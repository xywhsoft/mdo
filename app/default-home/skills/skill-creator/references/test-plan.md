# Skill 试用记录

创建 2～3 个有区别的用例：常见请求、不同措辞/输入、缺少可选值或资源异常。
每个用例记录输入、预期、是否实际执行、观察结果与修改依据。
技能可能改变环境时，在临时项目、样例文件或模拟服务上试用。

```text
用例：常见请求
输入：$example 实际任务
预期：输出格式、必须检查的事实、可以接受的边界
执行状态：待执行 / 已执行 / 因条件不足未执行
实际结果：只填已观察到的结果
改进：由结果支持的修改
```

用一组独立输入检查泛化，避免只针对某一条测试提示词写规则。
自动触发和手动调用分开记录：手动成功不能证明 description 自动匹配成功。
目录校验只检查结构与资源边界，不执行脚本，也不调用模型，不能替代这些试用。

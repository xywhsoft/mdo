# Web assets

Repository-owned icons, fonts, and other static assets belong here. Generated
bundles are written under `.build`, not into this directory.

`mdo-icon.png` and `favicon.ico` use the approved miniature M artwork.
`mdo-app-icon.png` and `apple-touch-icon.png` use the full square MDO artwork.
These committed exports include a dark background for contrast. Source artwork
and export instructions are in `assets/branding/README.md` at the repository root.

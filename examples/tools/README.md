# 可选外部工具范例

这些源码只用于开发和手动安装，不进入 mdo 安装包，不会自动注册。

## 会话计划：todo.c

`todo.c` 演示 `mdoModuleEntry`、`Registrar->AddTool`、参数 schema 和结果 writer。
模块 ID 是 `example.todo`，模型调用的工具 ID 是 `mdo.todo`。

安装方式：在设置的“工具”页导入 `todo.c`，保存并启用。也可以把源码复制到
当前 `mdo-home/tools/todo.c`，然后刷新工具目录。需要指定工具白名单的 Agent
应显式添加 `mdo.todo`；继承全部工具的 Agent 会在下次运行时取得它。

调用示例：

```json
{"items":[{"text":"检查项目","done":true},{"text":"验证结果","done":false}]}
```

每次提交完整列表，空列表表示清空；最多 24 项。示例仅返回计划快照，不操作项目文件。
成功的主 Agent 结果使用现有会话计划投影协议显示在计划栏，支持历史恢复、分支及备份；
未安装示例时，历史计划仍可读取，但模型没有这个工具。

停用或删除该工具即可移除其后续调用能力，已有会话记录和计划不会被删除。
若 Agent 显式引用它，先移除对应工具白名单引用。其他工具仍使用原有内置实现。

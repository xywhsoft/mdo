# MCP 自动启用实施记录

目标：安装并启用后自动配置、连接和发现工具；必要参数与鉴权才需要用户参与。版本保持 0.8.4，不发布线上。

分阶段提交：

1. 默认方案声明和跨平台校验。
2. 宿主派生稳定默认连接、私有覆盖、后台初始化、默认绑定与运行状态。
3. 安装信任提示、简化配置/登录入口、状态与安装回执区分、多语言。
4. 本地原生/浏览器回归、Computer Use 真实发现及本地构建。

默认连接使用稳定扩展 ID 派生标识，复用已有 MCP 运行时和私有凭据存储。没有私有覆盖时从已信任目录派生，修改时才保存到 `data/mcp/connections`。存在用户配置时复用，不重复创建。包内不保存用户配置。旧模板按其既有方案顺序选取当前平台默认；明确 `default: false` 的方案仅用于高级选择，显式 `default: true` 优先，同平台不得有两个显式默认方案。

禁止对用户日用客户端进行未验证的覆盖、关闭或会话修改。复用当前 SDK，顺序开发测试，不新建 SDK/工作树。不增加跟踪平台或绕过 Cua 行为的提示词。

## 实现

- 默认声明：`a7b206d0`。宿主生命周期：`6a30e1ed`。默认 ID 来自稳定扩展 ID 的 SHA-256；不依赖安装目录名、当前盘符或启动次数。
- 安装、启用、重启、SDK 安装和依赖组重载共用宿主目录发现，不依赖设置页面启动程序。已有私有连接优先，用户停用不会被重建或重新启用。
- 后台只初始化及发现工具，不重放工具操作。瞬时 IO、超时和 HTTP 408/429/5xx 最多五次尝试，共享最多 60 秒截止时间。目录替换前取消当前初始化并释放租约。
- 默认连接只有在安装目录及必需依赖的已授权摘要均匹配时自动运行。未授权的本机文件修改不能触发自动放行。
- 默认私有覆盖可以随已验证更新沿用。服务程序/目标、普通参数、方案或权限变化时阻断旧凭据沿用，要求重新审阅；普通元数据和支持文件更新不强制重新输入凭据。OAuth 仍按连接 ID、目标和 OAuth 声明保存。
- 列表区分正在连接、可用、缺参、待登录、待确认、停用和失败。必要操作直接出现在列表行；缺参表单使用公共窗口和固定底栏。只有必需的业务参数出现在精简窗口，额外账号和权限方案留在高级配置。
- 已安装但待配置/授权仍算安装成功，不重新下载。需处理的问题进入既有统一警告区域。
- 安装生效后的下一次发送（含该轮新创建的 SubAgent）读取当前目录，无需重启客户端或新建会话。正在发送的单次模型请求不被篡改，也不重放当前工具调用。
- 中文、英文、俄文同步。服务指南和运行时格式说明已同步，不再将旧的独立 MCP JSON 文件或手动测试作为安装使用前提。

## 验证入口

复用已有 `.build/host/xs.exe` 和 `deps.lock` 对应的 SDK overlay；所有夹具在本项目 `.build/`，用后清理，不复制应用或 SDK。没有调用收费模型，也没有修改日用 Home、账号和会话。

- `tests/test_mcp_automatic_native.py`：真实 ZIP 安装、后台 stdio/HTTP 初始化、稳定默认连接、重启保留停用、更新、凭据保持与目标变更阻断、缺参、瞬时失败恢复、有限重试、OAuth 等待、统一警告、文件篡改和卸载。
- `tests/test_mcp_directory_native.py`：原生目录及多个私有连接、脱敏、冷预览、修订保护、权限确认与退出清理。
- `tests/test_mcp_dependency_native.py`：27 项实际依赖程序、账号绑定、项目优先级、子角色继承与依赖摘要检查。
- `tests/test_mcp_runtime_data_native.py`：Python MCP 的可写数据目录、冷预览和重载保持摘要。
- `tests/manual_mcp_computer_use_acceptance.py`：校验官方六个文件并用硬链接复用，自动启动原版 Cua，发现 63 个工具，Agent `tools` 可见默认服务；不授予 existing-profile、不执行桌面操作。
- Node：自动配置交互、目标变更拦截、方案平台选择、商店列表分页、MCP 命令、多语言；另有原生 API/格式静态契约。
- 浏览器检查：列表直达配置、仅必需参数、统一窗口样式和固定底栏，截图保存在 `.build/mcp-auto-20261102/simple-configuration.png`。

本轮生成根目录 `mdo.exe` 供本地测试，版本保持 0.8.4。未发布客户端、商店包或平台服务。未进行本轮 Android 真机及真实模型桌面任务验收；Computer Use 的验证范围为真实协议初始化、工具发现和 Agent 发现入口。

# 缓存 Home 的旧数据导入事务

这项事务使便携窗口已经创建浏览器缓存时仍能显式导入旧数据。它只接受没有用户数据的 Home，不是通用合并、项目清除或备份恢复接口。入口和转换规则见 [旧数据迁移](legacy-migration.md)。

## 所有权与 API

`home_import.h` 提供只读 `Inspect`、取得暂存根的 `Begin` 和消费事务句柄的 `End`。私有实现 `home_import.inc.c` 由 `home.c` 包含，与 Home 共享锚定根、互斥锁和既有跨进程 `.mdo.lock` 租约，不依赖 unity 文件的偶然顺序。

- `Inspect` 不创建 Home。不存在的目标可用；已挂载目标只允许宿主锁和可选的 `data/cache/webview2` 真实目录。检查只到缓存父目录，不枚举活动浏览器内容。
- `Begin` 在 Home 锁内重新检查目标并保留唯一事务。普通 Home 写操作和外部路径借用立即拒绝；转换期间不持有 Home 锁，避免与配置管理器反向加锁。
- 暂存根由调用者拥有。调用者须先关闭全部暂存文件和根，再调用一次 `End`；事务必须在 `MdoHomeUnit` 之前结束。
- `End(true)` 校验并发布，成功后冻结写入直到重启。`End(false)` 放弃并清理。无法完成回滚或清理时保留记录、冻结写入，允许只读诊断。
- 项目租约仍在首次暂存写入前全部取得，保持到发布或清理结束。它与 Home 进程租约和写入冻结共同保护事务。

## 目录与阶段

```text
mdo-home/
  .mdo.lock                  原有进程租约；不移动
  data/cache/webview2/       原有浏览器数据；不遍历、不移动
  .mdo-import/
    owner                    固定格式所有者标记
    payload/                 已转换、经当前解析器校验的数据
    ready                    不可变就绪清单
    committed                不可变提交标记
```

发布的数据根固定为 `config`、`secrets`、`projects`、`sessions`、`memory`、`schedules`、`migration`。就绪清单只有版本、根位图及七项设备/目录 ID，不从清单接受路径。暂存树限制 8192 项、16 层，拒绝链接和特殊文件。

所有阶段标记以独占临时文件写入并刷新，关闭后锚定无覆盖改名。就绪清单发布后才逐项搬迁；全部成功后发布提交标记。改名返回句柄关闭错误时，恢复根据实际位置和目录 ID 判断结果。

## 启动恢复

恢复在挂载 Home 并取得进程租约后、配置及业务 manager 初始化前执行。完整检查先于任何回滚搬迁：每个已声明根必须恰好存在于暂存或目标一个位置，且设备/目录 ID 与清单一致。

| 记录状态 | 恢复行为 |
| --- | --- |
| 尚未就绪，目标仍只有缓存 | 删除本次暂存 |
| 已就绪、尚未提交 | 已搬迁根逆序返回暂存，之后清理 |
| 已提交，全部目标身份匹配 | 保留迁入的完整数据，之后清理 |
| 双位置、缺失、替换、未知项、标记损坏 | 拒绝启动并保留记录，不推断删除 |

清理先将整个 `.mdo-import` 无覆盖改名到 `.mdo-import-cleanup`。清理目录只删除自己的暂存与已知阶段文件，所有者标记最后删除；清理中断可再次执行。不会因提交标记已被清理而把成功导入误判为提交前状态。

本协议验证了进程中断恢复。阶段文件刷新不等于目录元数据同步；当前不宣称断电持久性，也不把这项协议视为项目清除事务已经实现。

## 有界验证

`tests/test_home_import_runtime.py` 在复制的源码中加入测试控制，正式应用没有控制接口。覆盖放弃、七个根搬迁前后失败、提交失败、回滚失败、准备/就绪/每个搬迁/提交/清理阶段进程退出、重复启动、未知用户数据、标记损坏、位置歧义和目录替换。缓存文件保持打开，回滚及提交后字节不变。缓存父目录与暂存链接拒绝保持外部哨兵不变；Windows 无符号链接权限时使用本夹具内的 junction，不修改系统权限。

`tests/test_api_runtime.py` 验证报告与发布失败清理、成功后的写入隔离、重启载入配置及来源/目标包含关系拒绝。`tests/manual_packed_migration_qa.py` 提供只有合成缓存及旧配置的真实单文件 HTTP 页面，检查两步确认、320×350 键盘流程和重启回放；不请求模型或修改真实用户 Home。真实 WebView2 便携路径另由发布门禁检查。

本次 Windows 门禁与打包页通过。Linux/macOS、实体移动端和原生窗口内的完整导入点击尚未独立验收；没有运行压力或高负载测试。

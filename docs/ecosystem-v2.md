# 九体系生态商店

本版分类为 Agent、SubAgent、工具、Skill、MCP、命令、扩展包（C 模块）、扩展工具包（命令行运行环境）、mdo 插件（应用 VFS 覆盖）。组合安装包是分发形式，保留组成资源的独立类型。

## 实施约定

- 沿用网站统一 mdo 插件、身份、审核和私有生态对象库；已发布 v1 包保持原始字节与身份。
- 新格式与旧客户端隔离。包和文件均不可变；同一作者、标识及版本的不同内容不能覆盖原版本。
- 本地查看、导入、草稿、卸载不要求网站登录；公开目录允许匿名读取，个人投稿和未公开资源保持身份隔离。
- C 模块通过现有模块运行时注册；工具与承载模块关联。命令行工具包提供程序清单和使用说明，不修改系统 PATH。
- mdo 插件通过已有 VFS 插件生命周期启用，显示文件覆盖及重新加载要求。恢复日志必须先于插件挂载恢复。
- 安装前先准备完整文件计划，核对平台、代码信任、所有权和本机修订；失败恢复旧文件及登记。
- 审核与具体 SHA-256 绑定，并记录审核者、决定、原因和修订；后台页面各自对应固定功能。
- Android 原生可执行文件沿用 APK 安装机制；脚本及数据可使用已安装解释器，不承诺直接运行下载的 ELF。

## 验收

九类包均需覆盖投稿、未公开隔离、审核、浏览和真实本地安装。组合包覆盖重复目标、资源冲突和失败恢复。需要配置及需要重载分别报告，不能以下载成功代替生效。补充断线、重复提交、损坏文件、恶意路径、旧目录升级、卸载保留本机修改和插件恢复启动检查。

发布需验证服务端实际运行时、客户端打包内容及原有扩展回归，保留上线前代码与数据库备份；不覆盖其他任务的源码修改。

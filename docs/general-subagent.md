# 内置通用助手

通用助手是一个普通的配置式 SubAgent 扩展，目录为
`mdo-home/subagents/general/`，包含 `extension.json` 和 `agent.md`。
逻辑 ID 为 `subagent:general`，运行 ID 为 `subagent.general`。

主 Agent 按需通过 `agent` 工具委派，任务说明应包含目标、必要背景、操作范围
和交付物。子任务使用独立上下文，父角色的 `delegation.context` 决定附带的
任务、摘要或历史。通用助手还启用环境及适用项目规则，并沿用现有用户指令、
记忆、Skill、知识库、外部工具和 MCP 来源的选择规则。

模型、协议、思考强度及模型输出额度跟随当前父任务；工具为 `inherit`，
权限继续受用户实时授权和委派效果上限约束。允许在授权范围内读写和执行，
没有将通用助手固定为只读角色。默认关闭再次委派，允许前台或后台执行，
并发仍由全局 SubAgent 配额管理。默认最多 128 轮，最终报告上限 64 KiB；
`task_timeout_ms: 0` 不增加独立的角色总超时，仍继承取消及父任务截止时间。
命令、网络请求及工具失败策略继续使用现有运行时规则。

最终报告说明完成情况、结论或修改、实际验证及遗留问题，附必要的文件位置。
需要主 Agent 决策时返回待确认事项；普通权限审批继续使用统一审批界面。
主 Agent 接收子任务结果，决定如何整合、重试或继续，不将子任务失败直接
当作主对话必须终止的原因。

首次安装和从旧版升级都通过已有内置 ZIP 安装机制补齐扩展。用户可以在设置
中编辑、停用、卸载；编辑后的角色作为本机自定义版本保留，也可以显式点击
“恢复默认”替换为随程序附带的角色文件（保留当前启停状态）。后续启动尊重已记录的选择，也不覆盖同目录下的自定义
内容或未经确认的本地改动。

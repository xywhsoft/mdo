# Windows 桌面版与服务版

下载后将压缩包解压到可写目录。桌面版双击 `mdo.exe` 启动，优先使用 WebView2
显示界面。运行时不可用或窗口初始化失败时，保留本地服务，等服务就绪后自动用
系统默认浏览器打开实际监听地址；不要求先下载安装 WebView2。也支持使用随程序
携带的 Fixed Version 运行时，按其启动配置选择内核。

浏览器回退只在启动窗口失败时触发，正常关闭桌面窗口仍会停止程序。回退后关闭
浏览器标签页不会停止后台服务；再次运行同一程序可重新打开页面。自动打开失败时
会显示可手动访问的地址。浏览器模式的原生内嵌浏览器功能不可用。

xs 的 `window.install_fallback` 默认值为 `browser`；仍可显式选择 `ask` 或 `silent`
安装运行时，取消或安装失败后使用浏览器。设为 `headless` 则不自动打开浏览器。
独立 `mdo-server.exe` 保持纯服务模式，不自动弹出页面。

发布目录只需要程序与一个 `mdo-home` 文件夹。没有这个文件夹时，程序使用内置
默认配置；首次打开窗口和保存数据时，会在程序旁按需创建它。会话、配置、附件、
扩展和浏览器缓存都保存在其中。请将程序与整个 `mdo-home` 一起移动或备份。

已有数据时，更新程序只需关闭墨斗后替换可执行文件，保留 `mdo-home`。
压缩包中的 `mdo-home/docs` 是说明和构建记录；无需删除原来的配置和会话。

桌面窗口自动记住大小、位置和最大化状态，保存在当前 Home 的
`data/ui/main-window.state`。移动／调整窗口后延迟合并保存，关闭时再保存一次。
最小化不会覆盖正常窗口的尺寸，重启会恢复可见窗口。更换显示器、分辨率或 DPI 后，
恢复位置会限制在当前显示器的可用区域；记录损坏时使用默认窗口，不阻止启动。

服务版运行 `mdo-server.exe`，通过浏览器访问 `http://127.0.0.1:5390`。
它提供相同的 Agent、设置和会话能力，窗口由浏览器显示。

需要指定其他数据目录时，在 PowerShell 中运行：

```powershell
.\mdo.exe -- --home 'D:\Portable\mdo-home'
```

服务版将上述程序名替换为 `mdo-server.exe`。`MDO_HOME` 环境变量也可指定目录；
命令行 `--home` 优先。不要同时打开两个指向同一 Home 的实例。

首次打开后可在设置中配置模型。登录账号后可使用账号具备权限的在线模型、搜索
和生态商店；仅运行本地模型及文件工具不需要登录。

本目录的 `build.json` 记录该程序的依赖、构建来源与摘要，可用于核对下载产物。

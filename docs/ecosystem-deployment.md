# 目录商店部署

当前实施记录：[2026-10-27 整目录改造](build-records/2026-10-27-extension-directory-rebuild.md)。该记录逐阶段区分已验证、暂存、上线与尚未执行的检查。

公开服务与权限、作品/上传/审核流程见 [目录商店](ecosystem-store.md)。本次不迁移旧格式运行时兼容分支。原官方对象使用一次性离线转换工具生成普通 ZIP，逐文件核对原摘要；发布程序默认预览，显式 apply 前备份。旧生态只私有备份，不继续作为公开运行依赖。

平台 SQL 来源为权威 C 存储代码；新库初始化拒绝覆盖既存数据库。源代码替换必须核对现场哈希，存在生产漂移时只添加必要接口，不覆盖网关/身份/计费并行修改。上线前准备回滚清单，重启后验证公开目录、ZIP 下载及匿名权限边界；失败立即恢复自有文件。

客户端八类产物必须记录共同源码指纹、锁定 SDK/宿主指纹、签名及实际字节摘要，公开下载与自动更新应指向同一对象。Android 真机结果与自动编译分开记录。

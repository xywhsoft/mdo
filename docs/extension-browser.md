# 扩展列表与详情浏览

详情采用公共窗口弹层，不再放在列表右侧。窗口在应用级顶层居中显示，独立于列表滚动；关闭后保留筛选、页码和列表位置。手机默认全屏。公共库接口见 [frontend-layers.md](frontend-layers.md)。

## 界面约定

- 设置的“扩展能力”导航顺序固定为：Agent、SubAgent、Agent 工具、MCP、Skill、编辑器命令、外部工具、知识库、插件。桌面导航与手机选择器共用这一顺序；编辑器命令沿用 commands，插件沿用 extensions。“扩展包”的导航与内容页已移除，旧 store 路由归到插件页。
- Agent、SubAgent、Agent 工具、Skill、MCP、命令、本机 C 模块与外部工具管理，共用 `extension-browser.js` 与主题样式。插件统一文件覆盖和可选代码加载；当前实现边界及后续机制见 [扩展定义与插件设计](extensions.md#插件定义加载与文件管理设计)。
- 列表显示图标、名称、两行简介、作者或来源、版本及当前状态。名称后的浅色小字显示平台确认的提交者用户名，作者与版权声明单独展示，不能用账号昵称冒充用户名，也不能把提交者推断为版权人；缺失信息明确说明未提供。长版权在列表节选，详情保留完整内容。商店资源提供按需加载的版本历史。
- 本机启停采用开关；编辑、导出、分享和移除放入更多操作。创建、文件导入和构建器放在创建菜单。内置 Agent 工具不提供卸载或全局启停，默认 Agent 不提供停用。
- Skill、Agent 工具与外部工具保留各自的本机及商店选项卡。列表不设置内部纵向滚动，使用设置内容的外层滚动及底部分页；详情使用公共弹窗，标题栏固定，仅正文在内容超高时滚动。搜索、状态和来源筛选改变后回到第一页。下载任务统一从顶部“查看快捷键”左侧进入，各扩展页不再添加任务区。
- 桌面底部分页统一显示条数、上一页、可直接点击的邻近页码、首尾页、省略号、每页条数与输入页码跳转（支持回车或“确定”）。当前页明确标识，首尾按钮禁用；超界数字归到最近边界，空白或非整数给出就地提示。切换每页条数回到第一页，刷新保留当前页，删除后收敛到有效页。手机宽度使用原有紧凑形式，仅显示上一页、当前页/总页数、下一页及每页条数，保持单行；特别窄时上一页、下一页显示方向符号，保留无障碍名称。不增加横向或内层滚动条。
- 商店游标结果累计保存并按作品 ID 去重，已加载页可直接来回定位；“下一页”按需加载后一批，失败时保留已有页并允许重试。最后一页尚未填满时，新结果先填满该页，避免跳过条目。未完成加载显示“已加载”条数，全部取完才显示总条数；页码跳转范围为当前已加载页，不虚构服务端未提供的总页数。搜索框未提交的草稿不改变当前游标所属查询。
- MCP 的启用开关和实际连接状态分别显示。未上线的类型不增加虚假的线上数据或操作。
- Android 外部可执行程序继续随完整版 APK 更新；不提供动态安装、自定义添加或卸载内置程序，预制程序及说明随 APK 更新，保留启停。
- 官方常用工具的推荐仍只通过首次使用提示触发，商店不设置特殊推荐区。
- 外部工具的“创建 / 导入 → 查看我的投稿”使用公共窗口，展示版本、状态、审核原因和撤回操作，底部提供刷新及关闭；不在工具列表下方插入投稿区。读取与撤回任务的后续状态同步到当前窗口，失败保留已有内容并提供刷新重试；关闭后迟到结果不重新打开窗口，快速重开复用尚未返回的读取。离开页面、切换设备、退出登录或销毁管理页时清理窗口，过期撤回按钮不能作用于新设备。

## 操作与恢复

保留现有原生 API、文件校验、安装计划摘要、事务和回滚逻辑。C 代码仍须先展示源码及计划，由用户明确确认信任；列表上的安装按钮只进入此流程。

详情读取与写入分别管理。切换条目、离开详情或切换设备后，过期响应无法写入当前详情。连接状态通知不等同于设备切换，不清除同设备上的草稿和详情。刷新失败时保留已经加载的列表。键盘可以操作行、详情页签、开关及菜单；刷新恢复列表操作焦点。

不增加组合分发、评分、虚构下载量或新依赖。

## 商店来源与后续扩展页范式

外部工具、Agent 工具和 Skill 已采用统一来源规则：用户新建或离线导入的内容保留编辑、导出和分享；商店安装的内容只提供启停、检查更新和卸载，以及只读详情与源码查看，不提供编辑、复制、导出成自定义资源、AI 改进或再次分享。即使安装者是作品提交者，也按商店副本管理，发布新版本应使用作者保留的本地源码或创作中心。

来源以持久安装收据为准，不能由请求自称来源或改过文件内容而消除。对应原生编辑、删除、打包导出和 Skill 来源复制接口同样执行规则；收据不可读时保留文件，禁止无法确认归属的定制操作。旧收据只能从作品 ID、owner、slug、版本和摘要全部匹配的商店记录补齐署名，不修改资源文件和历史版本摘要。

新建或重做其他扩展页面时，沿用以上两页、来源权限、署名版权、无内层滚动、分页和统一下载入口规则。本轮不扩大其他类型的操作改造范围。所有单选下拉框使用统一控件样式，箭头距右侧留白，文字保留至少 36px 的末端空间；多选列表和强制对比模式保留原生行为。

## 回归

`test_extension_browser.mjs`、`test_single_resource_store.mjs`、`test_external_tools.mjs` 覆盖选择和滚动恢复、键盘菜单、内置工具边界、迟到响应、C 信任与安装计划、失败刷新、重连、Android 限制、状态筛选及下载任务对应关系。旧组合包界面及其专属测试已移除，共用格式与安装收据测试保留；`test_navigation_refresh.mjs` 验证旧 store 链接进入插件页且会话位置不丢失。

`test_single_resource_store_runtime.py` 使用隔离的原生客户端和网站服务，验证发布、私有权限、审核、分类目录、源码下载、真实安装与注册、更新冲突、卸载保留修改以及迁移。浏览器回归使用同一隔离数据，检查深浅主题、390 像素布局、源码详情、编辑和启停，不访问生产账号或创建线上作品。

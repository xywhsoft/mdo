# 扩展列表与详情浏览

采用用户选定的桌面列表与详情侧栏。窗口宽度不足时，同一详情区域占据列表位置，返回后保留筛选和列表滚动位置。

## 界面约定

- Agent、SubAgent、Agent 工具、Skill、MCP、命令、本机 C 模块，以及扩展中心与外部工具管理，共用 `extension-browser.js` 与主题样式。
- 列表显示图标、名称、两行简介、作者或来源、版本及当前状态。完整路径、源码、许可和使用说明放在详情；商店资源提供按需加载的版本历史。
- 本机启停采用开关；编辑、导出、分享和移除放入更多操作。创建、文件导入和构建器放在创建菜单。内置 Agent 工具不提供卸载或全局启停，默认 Agent 不提供停用。
- Skill 与 Agent 工具保留各自的本机及商店选项卡。外部工具保留两页结构，下载任务有独立入口和进度区，相关工具行显示任务状态及百分比。
- MCP 的启用开关和实际连接状态分别显示。未上线的类型不增加虚假的线上数据或操作。
- Android 外部可执行程序继续随完整版 APK 更新；不提供动态安装、自定义添加或卸载内置程序。已安装工具仍可修改使用说明及启停。
- 官方常用工具的推荐仍只通过首次使用提示触发，商店不设置特殊推荐区。

## 操作与恢复

保留现有原生 API、文件校验、安装计划摘要、事务和回滚逻辑。C 代码仍须先展示源码及计划，由用户明确确认信任；列表上的安装按钮只进入此流程。

详情读取与写入分别管理。切换条目、离开详情或切换设备后，过期响应无法写入当前详情。连接状态通知不等同于设备切换，不清除同设备上的草稿和详情。刷新失败时保留已经加载的列表。键盘可以操作行、详情页签、开关及菜单；刷新恢复列表操作焦点。

本次只改造客户端界面及浏览行为，没有增加组合分发、评分、虚构下载量或新依赖。

## 回归

`test_extension_browser.mjs`、`test_store_panel_browsing.mjs`、`test_single_resource_store.mjs`、`test_external_tools.mjs` 覆盖选择和滚动恢复、键盘菜单、内置工具边界、迟到响应、C 信任与安装计划、失败刷新、重连、Android 限制、状态筛选及下载任务对应关系。

`test_single_resource_store_runtime.py` 使用隔离的原生客户端和网站服务，验证发布、私有权限、审核、分类目录、源码下载、真实安装与注册、更新冲突、卸载保留修改以及迁移。浏览器回归使用同一隔离数据，检查深浅主题、390 像素布局、源码详情、编辑和启停，不访问生产账号或创建线上作品。

# mdo 0.1.0 正式版

2026-10-11，墨斗首个公开正式版本。提供 Windows 桌面/服务版、Linux glibc/musl
桌面/服务版和 Android ARM64 精简/完整版。下载与更新均使用本次冻结来源构建的最终产物。

## 主要功能

- Windows 与 Linux 桌面工作台，项目、会话、工具审批、后台任务与计划任务。
- 自定义模型、内置在线模型、附件、搜索，以及可继续的会话历史。
- 会话分支、重新执行、回收站恢复和彻底删除；删除当前会话后进入新建会话。
- 账号记忆与自动续期。短期访问令牌失效不要求重新登录；断网启动保留记住的身份。
  服务端默认在连续 30 天没有有效联网认证后使会话过期。
- Android ARM64 精简版与完整版。完整版包含额外工具，两版使用同一应用入口。
- Windows、Linux 服务版，以及经过哈希校验的更新和可选工具包。

## 本次修复

- 修复会话移动到回收站时侧栏报错、当前会话残留和旧草稿回写的问题。
- 增加回收站彻底删除入口与确认流程，保留可恢复删除和永久删除的区别。
- 修复创建分支后回复操作按钮消失、必须滚动触发加载的问题。
- 移除普通 AI 回复中重复的 Agent 标注。
- 支持 `ssh-keygen -N ""` 等合法空参数，区分参数错误、权限不足与审批拒绝。
- 修复长回复无法加载、Android 版本切换沿用旧安装包，以及本地 API 来源校验缺口。
- Windows Python 工具包修订 3 恢复脚本同目录、当前目录和 `PYTHONPATH` 的标准导入行为；
  显式使用 `-I`、`-E`、`-P` 时仍遵循 Python 的隔离语义。
- 保留 exec/spawn/stop 的原生进程错误原因链、操作、系统错误码和系统说明，避免被通用
  执行失败文字掩盖；诊断中不附加命令参数、环境变量或原生错误 Data。
- 编辑失败时提供相关位置的有限上下文与行号，准确区分零匹配和多匹配；无相似候选时提示
  读取目标区域。精确匹配、CRLF 与整批原子写入规则保持一致。

## 使用范围

- Android 需要 ARM64 设备，最低 API 26。本次最终 APK 已在 Android 16 实机验证正式签名
  安装、精简版升级完整版以及两次重启后的设置和会话保留；最低系统及各厂商后台策略未穷举。
- Linux glibc 核心基线为 2.28；musl 核心静态链接。Linux 桌面窗口仍需要 GTK3 与
  WebKitGTK 4.1 或 4.0（至少 2.30）；纯服务版没有窗口依赖。
- Linux 数据目录应放在支持原子目录操作的本地文件系统；WSL DrvFS 不能替代完整
  数据迁移的原生文件系统验收。
- 断网时本地项目和个人模型配置可以保留、查看；在线模型、搜索与远控仍需要联网。
- Android 两版使用同一长期正式签名。旧开发签名不能直接覆盖安装：先在旧版中导出并核对
  会话和附件，再卸载旧版、安装正式版并导入。后续正式版支持同签名覆盖升级。

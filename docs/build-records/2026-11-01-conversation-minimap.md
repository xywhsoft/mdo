# 会话 minimap 独立索引与显示修复

版本：0.8.4。本轮仅修改、测试和构建本地 Windows 程序；不发布官网或更新渠道，等待用户明确授权。

## 原因

- 最近会话按完整回复块分页，用户输入可能不在当前正文页中。旧摘要投影只识别正文里的 `agent_start`，导致刚切换时导航没有条目。
- 导航摘要与正文分页游标混用，较早摘要必须点击 `⋯` 手动加载。当前正文不完整时，导航也不完整。
- 会话栏宽度小于 880 CSS px 时直接隐藏导航；计算高度时未扣除浮动任务和审批面板遮挡的范围。

## 处理

- 复用回复块已有、经过校验的 `action_prompt` 显示当前消息标记，不向正文插入重复的用户输入。
- 通过现有 `/turns` 轻量摘要接口独立建立导航索引，首次从最新摘要开始读取；按可见容量串行补齐，每页最多 64 条。索引读取不下载消息正文。
- 去掉手动加载摘要的省略号。能放下的导航完整显示；超过实际高度后可在导航内滚动，并自动补齐更早的摘要。点击仍只读取目标消息范围。
- 容量按会话实际高度扣除浮动面板遮挡后计算，随窗口、侧栏和面板变化更新；窄桌面会话为导航预留边距，移动端继续使用原有布局。
- 完整索引摘要带读取水位，防止不完整正文和跨页跳转覆盖摘要。会话/历史版本变更隔离旧响应；无进展或失败响应不自动循环，后台取消不弹错误，回到前台可恢复读取。
- 不新增持久化数据库或迁移；摘要复用现有有界会话缓存，正文保持分页。

## 验证

- `node --test`：历史、时间线、会话、历史窗口和缓存相关测试共 136 项通过，包含新增的独立索引、输入锚点、定向跳转和切换取消回归。
- `python tests/test_conversation_navigation_browser.py`：Chrome 与 Edge 各 22 项真实 DOM 检查通过，涵盖无用户节点的冷打开、窄会话、实际高度、浮动遮挡、176 条摘要、多页补齐、跳转、前后台恢复和过期响应。
- 以 `3b338a6b` 的旧导航模块运行同一浏览器场景，复现正文已有回复、导航仍为空且不会自动读取索引的问题；证据保存在 `.build/conversation-navigation-084/baseline.json`。
- `python tests/test_conversation_runtime.py --host .build/host/xs.exe`：实际 xs/TCC 摘要逆序分页、范围定位、超过 16 MiB 的历史、续跑、重启及替换历史检查通过；仅使用本地模型与临时测试数据。
- 未调用真实供应商模型，未修改用户运行中的会话或线上服务。

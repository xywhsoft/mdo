移除通知列表和单独的中间详情页。通知图标、气泡均直达目标：应用更新打开下载/安装
详情，登录提示打开账号窗口或账号设置，工具提示进入工具管理；后台配置的通知直接
显示完整纯文本正文，不根据远程通知的 action 字段跳转其他功能。图标超过三个仍各自
可点击，横向滚动和键盘访问，不再通过省略按钮打开列表。

后台通知提供“稍后提醒”和“关闭”。稍后提醒按目标和 id/revision 隐藏当前运行的提示，
普通关闭保留提示。原生 distribution 服务返回独立随机的 notification_session，只作为
公开 UI 生命周期标识，不复用账号或写入凭据，不持久化到 Home。sessionStorage 记录

影响新流程。启动时尚未读到运行标识的空渲染不能清除已有记录。窗口切换目标/运行代
时自动回收，旧操作与迟到的旧目标更新状态不能覆盖当前目标。

登录、下载中心和公共窗口行为。20 项前端契约、226 个模块解析及可达性检查通过。

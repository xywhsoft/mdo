## 本轮变更

- 新增 Browser Use 通用宿主能力及固定标签页／框架的脚本执行支持。

- 上下文超限、HTTP 413 和 GLM 1261 自动进入压缩恢复，已完成工具不重复执行。
- 摘要预算覆盖完整请求及纠错提示，拒绝后严格缩小实际输入，避免摘要再次超限。
- 摘要保留分段消息、工具结果与附件引用，修正 Anthropic 缓存输入统计及旧计数锚点。
- 压缩等待和重试报告进度并支持及时取消；手动压缩继续使用有界失败策略。

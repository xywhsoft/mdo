# 扩展安装临时故障自动重试（2026-11-01）

## 行为与边界

- 已确认的商店安装在原生 SDK 操作内部自动恢复，最多追加 5 次重试，即最多 6 次尝试。一次整组安装及其所有依赖共用同一预算，不叠加每个文件或请求各自的重试次数。
- 每次重新下载仍使用同一计划 ID、批准修订、版本与哈希，不重新生成计划或扩大用户已确认的安装范围。关闭前端页面不会中断后台重试；取消会打断退避且不再发起下一次请求。
- 退避依次为 250、500、1000、2000、4000 毫秒。中间的可恢复失败不结束父安装任务；最终失败保留最后一次真实原因。成功的 SDK 结果携带实际 `retry_count`。
- 重试仅发生在目录事务提交之前的读取、元数据获取或归档传输阶段。已提交后的运行时加载问题、恢复状态不确定、批准过期和目标/依赖冲突不会通过重复安装来掩盖。
- 作者投稿、上传、公布、下架等非幂等请求不自动重放。

## 分类

允许重试：有结构化证据的网络 I/O、超时、临时不可用、连接关闭，以及 SDK 明确标记的响应未传完；HTTP 408、425、500、502、503、504。

立即结束：参数、类型、资源上限、内存、权限、取消、确定不存在的资源、已存在冲突、不支持的能力、协议/元数据格式错误、TLS 证书/身份校验失败、重定向、归档大小/哈希/ZIP 校验失败、安装计划或依赖冲突。未带可验证临时信号的限流/配额响应及未知内部错误不会猜测性地重试，保留原因供用户处理。

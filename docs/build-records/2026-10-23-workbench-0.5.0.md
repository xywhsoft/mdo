## 实施内容

右侧工作区支持新标签页、拖动排序、固定、调整宽度、并排、展开／收起及布局恢复。
插件通过固定上下文的 SDK 注册和打开面板；标准适配器包含文档、计划、差异、网页预览、
浏览器、文件编辑器和画面流。文档可引用到对话，文件与资源保存使用修订前置条件。

C 的 `<mdo/workbench.h>` 与 JS 的 `sdk.panel/resource/browser` 从同一份契约生成。
资源原子持久化、归属和会话边界、窗口租约、动作结果与释放均由统一 broker 处理。
损坏的工作区文件保留原件并单独报错，不阻止聊天启动。

Windows 使用单独的 WebView2 内容环境；Android 使用无 Java 对象注入的内容 WebView，
通过可信主文档专用消息端口控制。浏览器支持导航、等待、快照、截图、选择器输入和点击，
并支持用户接管。隐藏的后台浏览器可以先执行任务，再展示为标签页。

回归期间修复了 C 命令工作者缺失新 SDK 头、跨会话面板被当前导航误拒、浏览器恢复后仍指向
旧窗口、插件激活等待 UI 回执造成互锁、大截图撑满意图日志、画面流 EOF 丢失末帧等问题。
流输入具有 epoch、顺序号、有限队列和释放信号；操作系统输入驱动仍由插件实现。

## 当前边界

Android 未做本轮真机回归，导航、输入法、系统回收后的恢复仍待验证。Android WebView 的
CookieManager 为同进程共享，能力明确报告 `profile_isolation:false`。

无原生后端的外部浏览器及其他平台只提供受限网页预览。远程控制模式中的浏览器执行于显示端；
目标设备的 localhost 服务需要插件提供可访问的映射，本版没有通用端口隧道。

Computer Use、Android Use 的实际设备驱动由插件提供，框架提供画面／输入承载；
接收驱动必须校验顺序与租约，并在过期时释放按键。可信 C 扩展不具备进程内崩溃隔离。

# 外部会话状态的便携采集保护

在唯一的 Mohists 开发 Home 中复现：主会话完成一个本地模型轮次、独立成员完成另一轮之后，完整备份仍返回 200，但仅包含 meta.json、snapshot.json、ui-events.jsonl。成员账本与编排状态位于 data/application 中，没有进入包。原有 restore_ready:false 是离线恢复验证说明，不能代替对此类遗漏的明确处理。

本次增加 session.mark_external_state 及公开原生辅助接口。扩展在发布会话目录外的数据前显式声明；instance.create 自动声明。声明写入父会话，使用现有 session data writer/capture 排他规则，不新增数据库或数据复制层。

完整备份、旧模型导出和设备传输共用的 stored capture 在采集前拒绝已声明会话，说明当前格式尚不能完整携带协作数据。HTTP 入口先报告持久边界，再打开根 Agent，故插件停用后也能给出同一原因。实际采集仍在独占租约内复查。内部回滚保留标记，便携包白名单拒绝导入该标记，不能用一个声明冒充缺失的上下文。

- 普通会话仍可导出完整文件包，其原生便携解码成功。

- 只有编排状态、尚未创建成员的团队也明确拒绝不完整备份。
- 团队成员及普通 SDK 持久成员均自动保护；HTTP 备份、旧导出与原生 stored capture 返回对应原因。

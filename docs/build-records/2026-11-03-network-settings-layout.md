# 网络设置输入框布局

自定义 CA 证书输入框占满设置内容行。不走代理的地址改为整行 textarea，最小高度 160px、六行，可垂直调整大小；支持每行一个模式或逗号分隔。

修正宽行网格的列宽，避免继承 `justify-content: space-between` 后列宽按内容收缩。多行地址在保存时转换为现有逗号格式，过滤空行并去除每项首尾空白；读取时逐行显示。配置协议和后台校验不变。说明同步中、英、俄三种语言。

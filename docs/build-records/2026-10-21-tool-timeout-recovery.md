# 工具局部超时误终止会话修复（2026-10-21）

## 问题与根因

检查对象为日常目录 `E:\software\mdo\mdo-home` 中“帮我重启rustdesk”会话。
仅只读检查该会话及运行状态，没有重新执行用户命令或修改会话数据。

三次异常均为 `web_open` 开始后约 10 秒直接结束运行：没有对应的
`tool_done`，运行结果为 `cancelled`，但 `cancel_requested=false`。
同期普通 HTTP 404、命令非零退出和文件工具失败均能正常返回工具结果。

使用真实原生 HTTP 客户端和本地延迟响应服务器复现，错误链为：

```text
xs.fetch TIMEOUT
  xrt.http.client TIMEOUT（总截止时间或空闲截止时间）
    xrt.http.call CANCELLED（关闭底层连接）
```

`MdoWebTransportKind` 原先遍历原因链时跳过 TIMEOUT，却接受深层 CANCELLED。
网页工具因此把关闭连接当成整段任务取消，绕过工具结果落盘、重试及连续失败计数。
恢复会话时仍存在未完成工具调用，可能再次遇到同一问题。

日常安装程序为 0.2.0、build 30000101，xs 提交为
`5cdc54eb7ca76518612bc1ffc70eb6873333d4f6`；修复前的当前源码同样存在该分类缺陷。
不能仅依靠升级版本号解决。

## 修改

- 在原因链中保留外层明确的 TIMEOUT，避免被连接清理产生的 CANCELLED 覆盖。
- 网页请求自身取消而任务令牌未取消时，返回普通失败工具结果。
  保留已有有界网页恢复策略：最多 6 次尝试、60 秒预算，并遵守任务剩余时间。
- 搜索共用分类器，因此同步修复 `web_search`；账号租约变化或子请求取消只结束
  本次搜索，不能冒充任务取消。切换账号时不向新账号提交原查询。
- 保留注册式搜索请求的同一请求 ID；旧版搜索 POST 在提交结果不确定时不自动重放。
- 仅真正的任务取消或任务总截止时间仍终止任务；没有吞掉手动停止。
- 对目前无调用点的通用网页错误适配器同步统一分类，防止后续复用重新引入问题。

## 内容

- 完善 Skill 发现、渐进加载、个人与项目管理、迁移、参数声明与展开，以及 Skill 构建器。
- MCP 支持并发排队、取消和截止时间、异常工具隔离、缓存刷新、项目隔离、配置迁移预览。
- Windows 与 Android 支持 MCP OAuth 发现、PKCE、凭据保存、续期及撤销。
- MCP 增加资源、模板、提示词、补全、结构化与图片结果、会话内表单询问、项目 roots 和进度；`/mcp` 可将提示词展开至草稿。
- 修复 MCP 命令说明遗漏翻译；修复操作错误分类，保留协议错误、会话过期与授权失败，避免把 HTTP 200 当成 HTTP 错误。
- 对不提供系统凭据保护的 Linux 宿主明确标示 OAuth 不可用，禁止开始授权，保留安全存储要求。
- 包含此前重启登录恢复、Android 系统分享、工具连续执行与设备直连/中转/项目传输功能。

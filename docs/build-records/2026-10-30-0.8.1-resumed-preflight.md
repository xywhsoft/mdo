## 尚未放行的原因

1. 广泛运行探针仍有失败。已确认的前提差异包括引用已删除的 `modules/agents/builtin_default.c` 等旧路径、裁剪 C 探针未链接新增的扩展实现、默认在线模型无测试登录、启动已初始化内置扩展身份但仍断言 Home 不存在，以及继续使用旧的平铺命令/模块结构。其余失败也保留原始错误，不能仅凭部分夹具过期就宣称整个版本已通过。
2. 历史完整清理回滚曾两次进入 `frozen=1` 的恢复保护。本轮不加诊断插桩的完整套件通过，但没有捕获原始失败错误链，未确认根因或产品修复，仍保留为未解决项。
3. SDK 流取消曾一次被分类为 network。本轮 12 场景均通过，取消返回 cancelled；仍未证明竞态已消除，不能声称修复。
4. 本轮遵循先自动测试和编译的安排，未做安卓真机、登录真实模型及双设备最终验收。

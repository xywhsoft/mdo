# 2026-10-25 主界面账号与设备公共窗口

功能提交 `26092567dc5658884ada0de4d19ca4e66072aae0`，版本保持 0.6.0。

未登录时，主界面账号入口直接打开公共登录窗口，保留原来的路由和工作区；已登录时
进入设置的账号页。设备入口先检查本机控制端身份，未登录则使用同一登录组件，成功后
自动接续公共设备窗口，取消则停留原界面。设置中的登录和切换账号也使用新组件。

登录窗口宽 32rem、高度随内容；设备窗口宽 48rem、高 75% 视口，标题栏和底部操作
固定，手机全屏。颜色、焦点隔离、Esc、最大化和拖动复用公共窗口库。移除旧静态登录及
设备 dialog 和独立样式。密码提交即清空，失败保留可重试窗口；关闭前取消原生授权，
关闭或销毁清空密码并中止读取。晚到的快照不能覆盖新操作或重新填充设备窗口。

保留账号边界：账号面板作用于当前目标，设备选择只使用本机连接器；远程账号不能
启动本机浏览器授权。Android App Link 固定提交本机账号管理器，避免查看远程目标时
误发回调。切换目标会销毁旧目标的登录窗口，不把未提交密码或旧写入转给新目标。

28 项 JavaScript 回归（账号窗口、账号状态、连接器续期、公共窗口、扩展浏览及下载
注册表）、20 项前端契约检查、225 个模块解析与可达性检查通过。新测试覆盖两条主入口、
登录失败、密码清理、浏览器授权取消、本机/目标隔离、回调路由以及关闭后迟到列表和
旧按钮失效。

真实浏览器加载完整产品主界面，以隔离的原生实例提供工作区，只有账号和设备接口由
回环夹具模拟；账号、密码和设备名称均为测试数据。验证未登录直接弹窗且不跳转、设备
入口登录后自动接续、已登录账号进入设置，以及桌面深浅主题。390×720、三倍 PPI
手机视口下，两个窗口没有横向溢出，设备窗口底部操作保持可见。没有登录生产账号、
调用模型、撤销真实设备或发起真实远程连接。

冻结功能提交生成 Windows GUI/服务版及正式签名 Android 精简/完整版，使用锁定的
兼容原生运行时。APK 结构、原生库、zipalign 和正式证书检查通过；两个 APK 的应用
负载均与本次生成的 app.xrtpack 逐字节一致。本次未做 Android 真机回归。

# 扩展排序与标签

- 九类扩展共享 `sort_order` 与 `tags`。排序值越大越靠前，同值按既有版本流水 ID 倒序；平台在分页前排序，本机列表在分页前排序。
- 标题及提交者后显示多个胶囊标签；安装收据保存商店排序、流水 ID 和标签，本机目录可在 `extension.json` 声明。
- 后台九类页面增加“排序与标签”操作，使用作品修订号防止覆盖并发更新。仅管理员可调整平台排序，复用现有权限和 CSRF 检查；投稿中的排序不影响平台排序。
- Python 初始化为 1000；原推荐七项初始化为 900，均标记“推荐”。Git 不在推荐组合中，Python 仍为独立可选项。初始化记录按作品保存，服务重启不会重置管理员后续调整。
- 数据库自动补充作品字段，保留扩展目录及不可变 ZIP，排序调整不生成新版本；官方后续构建及 Android 预制目录保留同样的展示元数据。

## 已完成

- Agent、SubAgent 各自的本机与商店列表，沿用统一搜索、分页、作者与提交者信息、版权许可、详情弹窗及全局下载任务。商店安装内容不能编辑、导出或再次分享。
- 配置式和独立 C 角色均可投稿、私有保存、申请公布、审核、下载、更新、查看历史、下架及删除。创作中心沿用普通用户 3 件 / 每版本 10 MiB、创作者 20 件 / 每版本 100 MiB 配额；审核附件计入同一版本容量，新版本待审期间保留原公开版本。
- 平台提供两个独立管理入口，沿用 `_component + layui table` 与待审核、已公布、未公布分类。预览配置、自有文档、C 源码及依赖时不编译、执行上传的 C 程序。
- 单角色使用 `mdo.extension.v2`，正文使用 `mdo.agent.v1` 并明确 `code:true/false`，最低客户端能力构建号为 `70000009`。客户端与平台共用纯格式校验头，旧组合包保留在通用入口，旧客户端不会收到无法安装的新角色。
- 分发仅包含角色配置、对应 `program.c` 和明确引用的有界 UTF-8 自有文档，不导出渲染后的系统提示、项目、记忆、会话或凭据。跨角色文件、绝对路径、路径别名、文件/目录冲突、二进制附件和错误开发方式均拒绝。
- 安装计划检查继承角色、固定模型、Skill、MCP 必需依赖；缺失或停用时阻止落盘。委派选择器核对实际可用角色，知识库和外部工具的可选选择器明确显示运行时解析。
- 配置、C、文档、收据共用持久事务。编译或绑定失败恢复原文件和收据；更新保留启停状态，发现本机修改不覆盖；卸载时有任一自有文件修改就保留整套角色。旧运行任务持有原代码 generation。
- 独立 C 角色从已发布描述符管理和分享，列表读取不触发编译或生命周期回调。补修分发及配对配置时原生行为被默认值覆盖的问题，保留布尔行为、模型与权限、零值预算及显式配置覆盖。

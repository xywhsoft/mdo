## 验证期间的纠正

完整前端检查发现既有目录编辑器使用了缺失的 `action.confirm` 语言键，补齐三种语言后整套重跑通过。

首轮 Linux 夹具 Home 位于 WSL 的 D 盘 9p 挂载，首次扩展发布因原子“不覆盖”重命名不可用而停止。直接 `renameat2(RENAME_NOREPLACE)` 探针在该挂载返回 `EINVAL`，在 Linux 原生临时文件系统返回成功。沿用历史 Linux 打包测试的方式，仅将小型临时 Home、工作文件和一个可执行文件放到原生临时目录，测试后清理；没有降低产品事务安全保证或添加非原子替代。四个 Linux 目标随后全部通过。

APK 扩展验收最初误要求共享 C 备用编号等于每版安装编号；核对实际 Java→元数据→环境→`MdoBuildId()` 链路后修正夹具，按签名包内生效编号验证通过。未因此修改产品编号逻辑。

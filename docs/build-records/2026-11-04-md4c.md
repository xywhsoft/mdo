# md4c 聊天渲染 Windows 验收

采用 xs 已有 md4c 扩展，锁定上游版本和库目录摘要。语法转换为有界结构节点，再由前端构造安全 DOM。
实现说明和预算见 [chat-markdown.md](../chat-markdown.md)。

## 最终行为

- 支持标题、复杂/引用式链接、嵌套列表、任务列表、表格、代码围栏、删除线、换行和字符实体。
- 图片支持 HTTP(S)、有限的内嵌 Base64、当前会话工作区及附件目录，提供预览、失败提示和重试。
- 文件支持中文、空格、Windows/POSIX 路径和 `@uploads/`；点击复用工作台标签页并定位指定行。
- 流式输出合并解析请求，复用稳定的图片/代码节点、滚动位置和焦点；切换语言保留尚未解析的正文。
- 解析超时、无效响应和预算超限时仍可阅读原文，过期响应不能覆盖新内容。

## 验证结果

最终包使用源码提交 `964f59e6`，收据标记应用工作树无未提交差异。此后只有浏览器测试断言和验收文档更新。

1. 全应用 unity 通过 GCC `-std=c11 -Wall -Wextra -Werror -fsyntax-only`。
2. 263 个前端模块解析及可达性检查通过；113 项 Node 测试和 30 项 Python 契约检查通过。
3. 实际打包程序通过原生 md4c 语法、Unicode、空正文及输入/节点/嵌套预算验证。
   公开 SDK 参数校验在解析前拒绝 NUL，返回 400；解析器预算超限返回 413。
4. 会话资源接口通过中文/空格/原生路径、原始 PNG 字节、`@uploads/`、本会话产物、错误类型、
   缺失文件、目录穿越、跨会话资源和 Windows junction 逃逸验证。
5. 真实打包 JS/CSS/语言包与原生解析服务，在中文/英文/俄文 × 1400/390 宽度的六组浏览器场景中各通过 25 项断言。
   包括图片重试/预览、持续输出时图片与代码节点复用、复制按钮焦点、动态语言切换、危险协议、
   晚到结果、忽略取消的传输、可读回退及无横向溢出。
6. 完整 mdo 页面通过工作台第 3 行定位、再次打开定位第 2 行并复用标签页、无未捕获 JS 错误三项检查。

浏览器焦点断言在关闭模态图片预览后进行，避免向浏览器禁止聚焦的背景元素请求焦点。
网页外链的原生分支只验证 `system.open` 路由，未实际启动系统浏览器；未完成 xs 原生 WebView、
Linux、macOS 或 Android 实机验收。未调用付费模型，未修改 E:\software\mdo 的程序、账号和会话。
公式、Mermaid 仍为后续显示组件范围。

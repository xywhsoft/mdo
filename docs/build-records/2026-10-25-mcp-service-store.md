## 验证

- 36 项真实 TCC 包格式测试；本机源代码与打包成品的原生配置回归，覆盖多实例、归属保护、修订冲突、密钥封存、可选清除、引用回收和 stdio 明确启动。
- Windows 与 Linux 成品均通过模板和 stdio 测试。当前 Linux 宿主缺少系统凭据保护时明确返回不可用；测试确认没有明文降级。Linux 成品是 native glibc 验证包，不作为经过旧系统 ABI 基线验证的公开发行版。
- 两个真实隔离服务验证客户端投稿 → 私有访问 → 公布申请 → 后台审核 → 搜索与下载 → 多连接 → 分别升级 → 下架 → 引用清理。没有生产测试账号、作品或模型调用。
- 原有 OAuth PKCE、重启恢复、刷新、401、临时失败和退出回归，以及能力、并发、取消、超时、非法工具隔离回归通过。九体系安装、回滚和卸载回归通过。
- 9 项 Node 行为测试、20 项前端契约、6 项 Application SDK 契约和 228 模块检查通过。浏览器验证桌面及 390 CSS px 手机窗口，无横向溢出、固定底部按钮；实际创建 API key 模板并私有提交成功。
- 两个正式证书签名的 Android 包通过签名与对齐检查，应用 pack 摘要一致，完整版保留 13 项外部工具。构建时发现五项工具缓存缺失，从当前已发布完整版 APK 以完整 SHA-256 校验恢复 606 个文件，保留原私有 SONAME 与许可。恢复收据位于私有构建目录。
- Android 本轮没有连接真机，未声称真机授权/后台行为已验证。

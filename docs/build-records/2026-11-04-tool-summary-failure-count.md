# 去除工具调用摘要的失败次数

工具调用分组标题不再显示红色“×次失败”计数；调用数量、工具名称、进行中状态和模型等待重试提示保留。展开后仍可查看每次调用的成功/失败状态及原始错误输出。没有修改工具执行、自动纠错、失败阈值或会话终态。

同时删除不再使用的计数样式及中、英、俄三种语言的对应文案。浏览器回归验证运行中与完成后的摘要均无失败计数，具体失败输出仍可展开读取，且原有折叠与实时更新行为保持正常。测试中关于对话分组的断言排除了另一项已完成的文件变更摘要卡片，避免与该独立功能耦合。

验证：17 项工具分组、终态及错误恢复检查通过；Chromium 中、英、俄三语言 × 1400px/390px 共 6 组检查通过，包含 13 项断言；264 个前端模块解析并连通。截图与浏览器记录位于 `.build/tool-call-groups/`。

没有修改版本号、重新打包或发布线上更新。

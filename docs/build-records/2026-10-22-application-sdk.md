# Application SDK 实施与验证

2026-10-22，在 `master` 完成 Application SDK 改造并按目标提交。版本保持 0.2.4；本轮交付本地测试程序，未发布官网或自动更新。

产品源码冻结提交：`a0862c1abf7c55cc2fd0d2b4a29ac9bab89c13d9`。测试程序的 Windows 构建收据确认该提交、工作区干净。本文作为后续独立文档提交，不改变程序内容。

## 实施结果

- `include/mdo/sdk.h` 提供统一 Application、类型化值、不可变调用上下文、错误原因链、服务与钩子接口。命令、工具、原生模块、Agent/SubAgent 和 JavaScript 插件共用应用访问层。
- 从生产路由生成 251 个产品服务入口（含别名），另有 63 个通用服务；从产品公开头文件生成 522 个原生函数绑定。原生头文件进入 TCC 编译环境，支持双引号与尖括号 include。
- 普通产品服务直接复用业务处理函数；物理 HTTP 接口保留原传输路径。修订、生命周期和写入门禁仍生效；执行中失败不会切换路径重放。
- 文件、VFS、扩展存储、凭据引用、精确 argv 进程执行、HTTP、环境变量和系统打开能力可由扩展调用。空参数保留，非零退出属于进程结果，基础设施错误保留阶段和原因。
- 异步操作有准入回执、取消、期限、分页结果及同 ID 去重；重启不会重放未完成写入。有界流提供背压、关闭后排空、过期及溢出处理。
- `model.complete` 复用产品模型配置、凭据、重试和计费路径；`tool.call` 复用受管会话权限与执行器。`MdoAgentSessionDriveNative` 允许原生 Agent 自行构造请求并驱动完整模型/工具/历史循环。
- 原生服务和钩子支持模块注册、显式覆盖内置服务与代际引用；热重载保留活动调用代码，Stop/Unregister 分别负责停止生产者与最终回收。
- 插件支持完整应用 VFS 文件覆盖、新增、修订、回滚、恢复启动，以及前端激活与清理。UI 提供明确窗口目标、动作回执、面板、菜单、快捷键、渲染器和编辑器。
- 既有命令接入共享 SDK；保留独立 Worker 的故障隔离和原界面行为。

开发文档为 `docs/application-sdk.md`；可运行 C 命令、原生 Agent 驱动模块和前端面板示例位于 `examples/application-sdk/`。

## 验证结果

- Python 单元与契约检查：158 项，155 通过、3 条件跳过、0 失败。
- 前端全量：1055 项，1054 通过、1 条件跳过、0 失败；181 个模块解析与依赖可达检查通过。
- Windows 严格 C11 `-Wall -Wextra -Werror` 编译通过；公共 SDK 头文件的 C11/C++17 编译通过。
- Android NDK Clang 对整个应用执行 ARM64 实际对象编译通过（`-Wall -Wextra -Werror -Wno-unused-function`；平台条件造成的既有未使用静态辅助函数除外）。对象无未定义的 `Mdo*` 函数，覆盖全部原生导出。
- SDK 原生运行与最终 Windows 打包程序均通过全流程探针：真实产品 CRUD、目录契约、值所有权、工作区外文件、Unicode/二进制、进程空参数/错误/超时、操作去重/取消/结果释放、流边界、插件回滚、UI 目标和 ACK、服务冲突与覆盖、热重载代际存活。
- 本机模拟模型验证 SSE、工具结果、用量和真实 SubAgent 委派；子 Agent 工具回调取得父产品项目及会话标识。C 示例模块实际编译并执行。
- 受影响的 Agent、模块、会话、运行管理、运行完成、产品 API、命令 API、Worker、上下文压缩及 POSIX 命令 SDK 运行时回归通过；打包默认工作区和模块目录检查通过。
- 两种 APK 均通过 Java/原生命令辅助程序编译、19 项安装文件策略与固定 SDK 集成检查、v2/v3 签名和 zipalign 校验。
- 最终 APK CRC、构建号、原生/数据映射、ELF 依赖闭包及 16 KiB ELF/ZIP 对齐通过。轻量版含 2 个原生文件；完整版含 76 个原生文件和 125 项工具运行时路径。两版包含同一份最终应用包。

验证日志位于 `.build/application-sdk-*.log`；Android 文件校验收据为 `.build/application-sdk-20261022/android-validation.json`。模型回归均使用本机隔离模拟服务，未调用付费模型。

## 使用边界

Android 为本地开发签名测试包，本轮未执行安卓真机回归。进程内原生模块属于受信任代码，SDK 不提供崩溃安全沙箱；命令 Worker 继续隔离命令崩溃。

插件多文件发布是文件级原子性，不是全局读事务。核心源码覆盖需要显式宿主重载，已有网页执行的 JavaScript 需要重新加载。恢复启动可设置 `MDO_PLUGINS_DISABLED=1`。

有界操作、流及传输预算、生命周期与值所有权详见开发文档；结果不确定时查询回执与目标状态，不因网络重连盲目重放有副作用调用。

# 九类扩展目录重构实施记录

目标以 `docs/extension-archive-design.md` 为准。单线程、主分支、小阶段提交；不创建仓库或大运行时副本。不保留旧发布格式、目录和版本兼容分支。

## 阶段一：共用路径和标准 ZIP（已验证）

- 新增九类类型及目录路径规则，安装名称可使用 XID，普通文件允许隐藏路径。
- 新增基于 xrt 文件/压缩/CRC/SHA 的原生 ZIP 读写；Store/Deflate、流式解压、空文件/目录、UTF-8、权限和标准数据描述符。
- Unicode 文件及父目录冲突检查采用生成的统一映射；限制大小、条目数量和路径，拒绝越界、重名、链接、设备名、重叠和校验失败。
- 原生回归使用现有 `127.0.0.1:58013` XS/TCC；临时 C 命令按摘要清理，没有模型或供应商请求。Python 标准库 ZIP 用于独立互操作核对。
- 28 个标准/异常归档用例、九类目录契约，以及原生写入后由原生和 Python 分别解压核对全部通过，包含 1200 个文件、ZIP64 本地扩展字段和 Unicode 父目录冲突。

后续阶段：目录登记/事务和 SDK → 九类发现、编辑及执行 → 平台、创作中心及官方 ZIP → 全链路及平台回归、上线。以上后续工作尚未完成，不以 ZIP 基础能力通过代替整个任务完成。

## 阶段二前置：目录根清单（已验证）

- 增加小型 `extension.json` 契约：类别、显示名称、调用别名、相对入口和平台；安装标识不再由调用名称承担。
- ZIP 根必须直接包含清单；拒绝旧 JSON 包字段、旧分类、外层 payload 包装及缺失的声明文件。
- 原生用例扩展至 44 项，覆盖九类清单和错误声明，标准 ZIP 双向互操作继续通过。

原有 `app/xs.json` 和 XRUDP 测试改动保留。阶段一回归证据在 `.build/extension-zip-native/native-result.json`。

## 阶段二：共用目录存储与事务（已完成原生单元验证，尚待运行时接线）

- 新增 `extensions/manager.c`：九类物理目录枚举、清单与相对入口、XID/别名分离、目录内容摘要及整目录 ZIP 导出。
- 安装先解压到宿主任务目录，逐文件校验，再替换唯一的 类型/标识 目录；卸载删除完整目录。事务日志只含路径身份、阶段及原登记，不含文件内容。
- 更新保留启停状态，清理旧目录中不再存在的文件；源码辅助文件也参与摘要。商店来源不能重新导出，实际文件修改后不能通过执行前校验或重新启用。
- 原生测试对九类分别执行安装、更新和完整卸载，覆盖代码许可、XID 大小写别名保护、损坏更新不破坏旧目录、prepared 安装/卸载恢复、首次安装回滚、committed 只清理及非法日志不影响目录外文件。
- 测试只创建项目内的小型文件系统夹具，并在结束后删除；复用现有 XS/TCC，不创建新的应用部署。收据在 `.build/extension-directory-native/native-result.json`。
- 九类实际运行时、API、SDK、平台、前端及官方工具包接线尚未完成；此阶段通过不代表发布链路已完成。

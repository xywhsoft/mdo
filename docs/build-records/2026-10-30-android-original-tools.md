完整版 APK 从 474,036,328 字节（452.08 MiB）减少到 85,036,681 字节（81.10 MiB），减少 82.06%。根目录 `mdo-full-arm64-v8a.apk` 已重新生成，版本为 0.8.1 / `05000801`，Android 安装编号 70000088；本次没有发布官网或更新。

## 原因和修改

旧构建器遍历整个 Android 工具素材目录，把后来添加的 Git、SQLite CLI、Poppler、FFmpeg、ImageMagick 也装入 APK。它没有区分线上可分发工具与 APK 预置工具；其中 Git 的目录 ZIP 和独占原生映像合计约 267 MiB，是主要体积来源。

`tools/android/runtime_bundle.py` 现在明确固定最初八种工具：BusyBox、curl、jq、OpenSSH（含 SCP/SFTP 等附属命令）、aria2、ripgrep、7-Zip、Python。增加商店工具或素材目录不会再自动扩大 APK；选定的原始工具缺失时构建失败，避免静默生成残缺的完整版。商店元数据和五种新增工具的分发素材保持原样。

同步更新包体检查、真实设备验收清单及文档。升级验收检查当前 APK 的八种工具可用，允许旧版已经留下的额外目录继续保留，不删除个人数据。既有设备的升级行为本轮未实际执行。

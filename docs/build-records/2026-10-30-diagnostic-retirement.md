# 诊断入口整理与旧存储页面退役（2026-10-30）

所有当前异常诊断共用通知区域的一个警告图标，点击用公共 Layer 弹窗显示原因、位置和处理建议。没有异常时隐藏图标；重新检查失败时保留上次结果，检查恢复后移除已解决的条目。

## 修改

- 删除设置中的“诊断与存储”菜单、页面、专用读取状态和渲染代码；会话、计划任务等诊断不再链接到已删除页面。
- 保留现有模块、Skill、MCP、插件、扩展、知识库、会话及计划任务的有效诊断，并加入临时存储、存储一致性恢复要求重启两类警告。正常的延迟创建 Home 不报警。
- 警告读取独立于在线通知及更新检查，30 秒刷新，每次最多等待 8 秒。慢速更新请求不阻塞警告展示或重新检查；设备切换和运行代次变化会丢弃旧请求。
- 删除旧版 `.mdo` 数据转换器、Home 导入事务、旧预览/确认 API、语言与样式、专用测试及文档。`/api/v1/storage` 和 `/api/v1/migrations/legacy` 已下线。
- 将当前恢复、删除事务仍使用的四个根目录约束文件操作提取至 `home_fs.inc.c`。保留进程租约、原子写入、路径安全、会话恢复、删除日志及收据；不清除用户的旧数据目录。

产品提交：`c76756d7`。版本保持 0.8.0，本次没有发布官网和自动更新，也未替换真实安装。

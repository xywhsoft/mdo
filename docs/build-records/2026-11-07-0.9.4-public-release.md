## 本轮变更

- 模型向导新增“不验证添加”，结构校验与凭据保护照常执行，跳过上游调用并保持未验证状态。
- 模型目录提供温度、思考及推荐输出预算；验证、Agent、SubAgent、Application SDK 使用相同默认值，保留显式覆盖及温度 0。移除固定 8K 预算，已有配置可点击使用推荐预算。
- 修复 DeepSeek 思考模式下的自动工具验证与 reasoning_content 结果回传。
- 账号恢复使用连续失败计数和有界退避，成功后清零，减少短暂认证故障导致的中断。
- 区分模型额度与账户请求、消费上限，完善错误信息。
- 修复备份恢复时源会话活动时间早于目标创建时间导致的元数据验证失败，导入后清除旧运行结果。

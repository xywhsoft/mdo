# 知识库生态接线与上线

客户端产品源码冻结在 `e0f3ffce`，平台冻结在 `ed3ae86e`，均提交到 master。版本保持 0.6.0；没有替换官网客户端安装包或发布自动更新。

## 已完成

- 本机知识库目录、元数据、文档编辑及目录/JSON 导入；提示词与用户描述独立，作者、提交者、版权和许可沿用扩展范式。
- 本机/商店分页列表、筛选、公共详情弹层、全局下载任务、启停、版本历史、更新和卸载。商店资源不提供编辑与再次分享。自定义编辑和下载安装均复用持久回滚日志；自定义资料不残留安装收据。
- `{$path}` 替换成 `@knowledge/<id>`，明确挂载当前 Home 的资料目录。主 Agent / SubAgent 按需查阅；只读任务也可读取此挂载，越界仍拒绝。停用或关闭注入后移除旧提示，坏元数据不打断正常注入。
- 客户端投稿及网页创建、目录导入、预览、私有保存、公布申请、审核、版本更新、下架及删除；配额和审核附件复用现有创作中心。
- 后台独立“知识库管理”，复用 `_component + layui table`，待审核/已公布/未公布按钮和筛选，审核资料显示提示词、目录、文本预览和版权信息。
- Application SDK 使用相同扩展资源路由；增加只读文件列表和有界预览，无隐藏 UI 存储。

## 验证

- 44 项真实 TCC 包校验，包含知识库索引、二进制索引拒绝、路径别名、文件/目录冲突、保留元数据路径、执行钩子拒绝和提示词上限。
- 原生 API 与空目录启动的 Windows GUI/服务版、Linux 成品回归，确认没有借用源码覆盖成品。包括 SDK 列表、文件/元数据修订、外部修改冲突、注入开关、坏库隔离、只读任务真实 read/grep/glob、目录越界、二进制/64 KiB 预览、大于普通 API 256 KiB 上限的保存、收据归属和卸载。
- 故障注入在部分文件写入后失败，完整恢复元数据、文档和收据，移除待恢复日志；作者保存复用已通过 CAS 的同一文件快照，避免重新采样后覆盖并发修改。
- 两个真实隔离服务验证作者创建 → 导出 → 私有保存 → 公布申请 → 审核 → 商店下载 → 新版本待审及公开替换 → 保留停用状态 → 下架 → 保留本机修改。包含 300 KiB 单文档：知识库统一生成 v2，避免落入旧格式的单文件上限。
- 14 项 Node 行为测试、20 项前端契约、6 项 SDK 契约、230 模块解析和可达性检查通过。原有九类组合包安装/回滚/卸载、MCP 模板原生回归通过。
- 浏览器实际创建、保存并重新编辑知识库；网页生成并私有投稿成功。390 CSS px、3 倍 PPI 验证正文无横向溢出，底栏固定在 659–719 CSS px，正文在其上滚动。证据位于构建目录。
- Linux 测试使用原生 Linux 临时目录。WSL 的 Windows 挂载盘不支持 `renameat2(RENAME_NOREPLACE)`，目录删除会拒绝并保留资料；没有改成可能覆盖已有目录的非安全降级。Linux 成品为 native glibc 验证包，未验证旧系统 ABI 基线。
- Android 精简/完整版均通过正式证书签名、v2/v3 签名与 16 KiB zipalign 校验，app pack 摘要一致；完整版保留原有 13 个外部工具。本轮未连接手机，未声称真机回归通过。

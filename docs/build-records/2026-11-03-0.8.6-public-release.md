## 发布内容

- 新会话首条消息在后台调用专用 Ornith 接口生成标题，无需登录；失败时使用首条消息摘要，手动标题优先，不阻断主对话。
- Agent、模型和推理强度在同一弹层选择；支持安装的 Agent 接管普通会话，紧凑入口仍只显示模型和强度。
- 内置 Agent 工具可以启用、停用，todo 显示名统一为小写；未勾选扩展信任确认时提供明确提示。
- 手动压缩与运行时检查串行，缺失 Agent 时保留可操作的错误信息。
- 完善插件前端接口的资源归属、账号会员信息布局和网络绕过地址编辑。
- Android 完整版仅预置 BusyBox、curl、jq、OpenSSH、aria2、ripgrep、7-Zip、Python 八项工具；源码下载继续停用。

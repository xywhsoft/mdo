## 验证

- 代码与 Android 真机验收见 [前一轮记录](2026-10-25-code-and-android-acceptance.md)：182 项 Python 检查、1,187 项前端测试及独立 Android 16 ARM64 真机测试。没有付费模型调用，也未覆盖日常 Android 安装。
- 本轮重新构建正式 Windows 宿主。首轮发布检查已通过单位、前端和严格 C 检查；修正旧测试后以可追溯续跑完成全部 116 项运行检查、13 项实际成品检查、五项 WebView2 检查、绿色 Home 迁移及 20 秒打包启动观察。续跑每次重新打包并与首个候选逐字节比较，产品输入和原生宿主哈希保持不变，未把失败运行改写成通过。
- 四个 Linux 成品由 Debian 10 基线编译，分别验证 ELF/ABI，并在原生 Linux 文件系统完成共 60 项成品、知识库及 SDK 检查。另将两个 glibc 成品放入实际 glibc 2.28 用户空间运行知识库回归。构建器最后的普通卸载因另一任务使用共享绑定目录而返回非零；四个编译输出及回执完整，保留共享挂载，没有强制卸载或重启 WSL。
- Android 两版采用既有正式证书，包名 `org.xleaves.mdo`、不可调试，通过版本、CRC、原生依赖闭包及 16 KiB ELF/ZIP 对齐检查。正式包的 app.xrtpack 与 libxs.so 与真机验收一致。完整版缺失的三个字体数据文件从哈希核验通过的上一正式 APK 恢复，保留字体许可证后重新签名与校验；未更换原生工具库。
- 线上通过真实 HTTPS 路由完整读取并校验 34 个响应（更新、旧接口和官网文件），覆盖八个渠道、完整 Android 大包、19 个官网文件以及版本码前缀兼容选择。公网另核验八渠道更新元数据、下载大小、三种语言页面及完整 Windows 文件 SHA-256。Android 大包的公网验证为元数据/HEAD，完整内容哈希在生产 HTTPS 本地路由验证。

## 本轮测试修正与复查

- 独立 Agent、运行器、会话和计划任务夹具补齐知识库模块；设备传输草稿明确按 UTF-8 读取。
- 旧生态组合测试明确主分类为 Agent，并要求商店资源导出返回 403；未来兼容下限测试覆盖所有平台构建编号。
- WebSocket 关闭检查接受已经排队的状态/心跳通知，同时仍严格验证协议关闭码，避免依赖线程调度顺序。
- 项目清理的首轮前端子进程失败及崩溃检查点超时未捕获到充分原因。补充子进程输出和执行结果诊断后完整回归通过，前端七类用例另重复两次均通过；保留失败日志，不据此编造产品根因。
- 发布准备器不再混入退役的整体工具包目录，并接受本轮公开更新说明。

## 线上操作与数据保护

- 平台仅同步版本码分发的四个文件，以及知识库 v1 兼容下限的四个文件；两项均先在生产原运行时的隔离站点验证，再分别短暂重启服务。没有部署其他任务的模型、附件、身份或 SDK 工作区改动。
- 发包前再次比较原程序、xs.json、官网原文件和旧二进制哈希、目录修订号。官网目录 inode 保持不变，逐文件原子替换；八个安装文件同时进入平台不可变对象存储。
- 通过正常登录、CSRF 和修订冲突检查更新目录。临时发布管理员已注销并删除，原管理员凭据比对未变；没有恢复覆盖线上账号、会话或计费数据库。原程序及 xs.json 哈希未变，服务保持 active。
- 私有备份与诊断证据保存在 `/home/xs/mdo-release-0.6.0-20261025-60000017`；本地证据位于 `.build/release-0.6.0-20261025`，没有保存原始登录令牌或签名密码。
- 官网三种语言下载页及更新接口均返回 0.6.0；公开下载目录没有源码 ZIP。

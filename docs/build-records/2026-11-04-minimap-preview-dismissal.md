# minimap 预览移开后不消失

根因已复现：每次回复流更新摘要时，`update()` 都通过 `show()` 刷新已打开的预览。`show()` 会取消鼠标离开时设置的 160ms 关闭计时，因此持续生成回复时，关闭任务反复被取消，弹层会一直停留。

修复将交互打开与内容刷新分开：鼠标进入、键盘焦点可以取消关闭计时；摘要刷新只更新文本和位置，保留既有关闭计时。合并重复的离开/失焦计时，防止旧计时在鼠标已进入预览后又误关闭。移出整个导航区域仍会关闭；窗口失焦、页面进入后台、指针操作取消则立即关闭。返回前台不会重新打开旧预览，销毁组件会释放新增监听和计时。

验证：

- 在修复前源码上，新增真实 Chromium DOM 回归稳定复现“离开标记后，摘要持续更新导致预览不关闭”。证据：`.build/minimap-preview-20261104/baseline.json`。
- 修复后浏览器的 35 项检查通过：流式更新中离开标记、离开预览、从标记移入预览、多次离开/失焦计时、快速切换标记、键盘焦点、Escape、窗口失焦、指针取消、进入后台/恢复、索引预取、可视区域限制及会话切换等。证据：同目录 `fixed.json`。
- 44 项相关时间线、历史索引、导航和实时更新检查通过；264 个前端模块解析并连通。

只修改客户端前端及回归测试，没有修改版本号、重新打包正式程序或发布线上更新。

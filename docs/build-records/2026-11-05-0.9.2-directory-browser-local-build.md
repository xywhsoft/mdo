# 0.9.2 本地测试包 r8：公共目录浏览器

本轮未发布线上。保留现有 0.9.1 下载和更新快照，未替换仓库根目录发布程序。

## 实现

- 创建/编辑项目使用公共目录浏览器：历史导航、面包屑与完整地址、补全、快捷位置、盘符、收藏和最近选择。
- 服务端自然排序与游标分页，支持当前层筛选、新建目录，解决原有 128 个目录和 4096 个文件枚举截断。
- 单窗口切换项目表单和目录浏览器，取消/返回保留已填内容；异步过期结果不能覆盖新窗口或待输入路径。
- 手机全屏、快捷位置折叠、确认底栏固定，适配软键盘；统一 SVG、深浅主题和中英俄文本。
- Android 默认位置使用应用可访问的 Home，提供用户主动打开的系统存储权限入口。
- 目录列表、位置和创建能力接入 Application SDK；目标设备变化会关闭旧浏览器，不回退成本机路径。

组件和接口说明见 [公共目录浏览器](../directory-browser.md)。

## 验证

- Windows 原生 C/TCC 目录回归、严格 GCC 编译通过。
- 27 项 Node 测试、12 项 SDK 契约测试、267 个前端模块检查通过。
- 中文/英文/俄文各 1400 和 390 宽度，共 6 个真实 Chromium 场景通过。
- 实际打包 EXE 在 1400 和 390 宽度通过原生 API、含空格/加号/中文路径、新建目录、项目保存与 SDK 联调。
- ARM64 真机独立 QA 包使用正式 APK 完全相同的应用包和运行时，300 个目录分页、筛选、创建、SDK 及真实 WebView 流程通过；实际视口 361×710，11 项界面检查通过。
- 安卓网络恢复、取消/续跑、凭据/草稿持久化、进程输出和扩展目录读写回归通过。这组测试在仅影响目录快捷位置的最后修正之前执行，未修改对应运行时。
- 正式签名、精简版内容、16 KiB 对齐和 Windows GUI 子系统校验通过。

## 交付和现场

程序位于 `D:\GIT\mdo\dist\0.9.2-r8\mdo.exe` 和
`D:\GIT\mdo\dist\0.9.2-r8\mdo-arm64-v8a.apk`；大小和 SHA-256 见同名 JSON 收据。
版本仍为 0.9.2，仅安装序列递增。正式精简版已覆盖安装到手机，保留应用数据。

手机 USB 调试在切回正式应用后再次失去响应，因此未将正式应用的最后一次 bootstrap
或账号恢复检查标记为通过。独立 QA 真机验收已完成；误建的一条正式应用测试会话由用户
确认删除，不声称自动清理成功。未删除其他账号、会话或项目。

Linux 的额外本地探针在现有运行时/Windows 挂载工作区组合下，因启动时原子无覆盖目录
重命名不可用而提前停止，尚未进入目录测试；本轮不计入 Linux 通过项，未构建或发布 Linux。
真实跨设备目录访问未做联机验收，自动化覆盖了目标隔离、关闭和不降级到本机的规则。

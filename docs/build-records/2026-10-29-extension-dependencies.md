## 验收边界

- 尚未进行生产部署、线上真实账号/审核流验收，或 Android 真机验收；其他 GUI/架构产物没有在本轮重新构建。
- Linux Home 所在文件系统必须支持安全的原子 no-replace 目录改名。WSL 的 Windows 挂载盘在本机不支持该操作，因此验收 Home 使用 Linux 原生临时目录；不降低原子性要求。
- 旧商店归档不被补写元数据，需作者按同一作品提交新版本。无法自动判定的 C 引用和旧插件版本条件需作者核查。
- 实际导出/运行配置错误返回运行未就绪，保留已提交文件和启用意图；依赖声明不替代代码信任或权限。


实现取舍：首版使用有界图快照重建和执行前复核，没有跨请求图缓存，未宣称大规模性能结果。开发时用不同的逻辑 ID / Home 隔离内容；不提供本机替代商店身份或项目固定不同版本的管理入口，身份或内容冲突会明确拒绝。可选依赖的额外清理、草稿集合发布等后续管理入口未纳入此次公开功能。

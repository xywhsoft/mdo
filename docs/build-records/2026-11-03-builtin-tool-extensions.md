## 结果

- `todo` 的扩展名称、模块名称和工具名称统一为小写。
- 21 个宿主实现的工具与 `todo` 一样，都是 `mdo-home/tools/<名称>/`
  下的内置 C 扩展，各有 `extension.json` 和 `tool.c`。
- 使用已有扩展身份、信任确认、依赖操作计划、启停、卸载与持久化机制，
  没有增加另一套内置工具设置或启停接口。列表只读取扩展目录清单。
- 新 SDK 入口 `mdo/builtin_tool.h` 可将 C 扩展绑定到宿主已有工具；
  宿主继续提供实际参数定义、执行逻辑、权限检查和任务执行环境。
  `todo` 继续使用普通 `AddTool` 提供实现，两者共享扩展生命周期。
- 主 Agent、SubAgent 和模型验证均遵循已启用的扩展清单。
  停用或卸载宿主工具目录后，不会通过 SDK 自动注册恢复调用能力。
- 未勾选信任确认时，点击应用会显示红色提示、聚焦复选框，且不发送写入请求；
  勾选后恢复正常操作。启用计划及 ZIP 导入共用此提示。
- 中、英、俄三种语言保持工具说明及来源展示；内置扩展不再误标为本机添加。

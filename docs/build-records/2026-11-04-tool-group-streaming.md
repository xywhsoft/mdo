# 工具分组在持续思考时闪烁、无法展开

根因是时间线按整个分组内容计算渲染签名。每个思考片段都会改变签名，进而替换工具分组、标题及已经展开的所有详情节点。如果更新发生在鼠标按下和松开之间，原来的标题已脱离文档，点击无法完成展开；即使已经展开，也会反复重建详情。

改为保留工具分组和标题，只更新数量、工具名称、运行状态和重试提示。内部记录按稳定键复用；没有变化的工具详情不再重建。持续思考的折叠标题及正文容器也保留，只更新文字。收起的分组继续按需创建内容，展开时呈现最新记录，沿用原来的滚动位置、会话隔离及折叠状态管理。

验证：

- 新增真实 Chromium 回归，在按下标题后连续更新思考，再松开点击；旧代码无法保留标题、焦点或完成展开，修复后通过。
- 覆盖持续更新时展开/收起、工具详情节点和选中文本保留、思考正文更新、工具新增/完成、重试和最终完成状态。
- 工具分组回归通过中文、英文、俄文与桌面/窄屏共 6 组场景。
- 思考滚动回归通过桌面/窄屏，覆盖阅读位置、跟随底部、折叠恢复、其他工具更新及切换会话。
- 108 项时间线、分组、滚动和模块检查单测通过；实际前端 264 个模块解析及引用检查通过。

保持 0.9.2，仅更新本地测试包，不发布官网或自动更新；包文件和校验记录另存。

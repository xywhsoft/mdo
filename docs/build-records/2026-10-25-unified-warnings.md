# 统一警告入口（2026-10-25）

产品提交：`f5934009`（知识库检查与可选存储降级）、`a8b5e548`（统一警告弹窗）。均在 master。

## 行为

通知区域将当前诊断及后台 warning 通知汇总为一个黄色图标，显示警告数量。点击使用公共 Layer 窗口展示每个问题的原因、路径与处理建议。正文滚动，底部“重新检查 / 关闭”固定；条目可定位设置，后台警告保留逐项“稍后提醒”。

知识库检查纳入现有只读 `/api/v1/diagnostics`，SDK 通过 `product.diagnostics.get` 获取。缺失可选目录和主动停用不报警；目录被文件占用、元数据无效、索引不可读及检查预算超限会提供结构化诊断。根目录被文件占用时保留原内容，任务初始化跳过知识库继续执行。已恢复的知识库检查结果在新快照中自动移除。

查询失败保留上次结果并标识检查不可用；设备和服务运行代次变化关闭旧窗口，迟到响应和旧按钮失效。警告正文采用纯文本渲染，偏好存储仅保留指纹。后续接入方式见 [统一警告入口](../diagnostic-warnings.md)。

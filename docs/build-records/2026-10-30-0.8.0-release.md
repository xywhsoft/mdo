0.8.0 已发布至官网下载和应用内更新，八个渠道全部 `required=true`，线上目录修订为 30。语义版本为 `05000800`，安装构建号为 70000065–70000072。保持已确认的 `0x05` 前缀及独立安装序号规则。

| Linux glibc 桌面版 / 服务版 | 70000067 / 70000068 |

| Android 精简版 / 完整版 | 70000071 / 70000072 |

下载页：https://mdo.xywhsoft.com/download/ 。完整发布说明：https://mdo.xywhsoft.com/download/release-notes-0.8.0.html 。三个语言页面的版本、大小、构建号、链接和 SHA-256 已同步；源码下载继续撤下。

## 随发布完成的修复和商店更新

- SDK 结果发布仍使用配置中的相对路径，进程输出单独持有绝对根目录。旧 ArtifactStore 以外的发布路径不再被破坏。提交 `5e451877`，四组针对性 SDK 回归通过。
- 发布准备脚本增加 `--required`，本次八项发布记录全部显式开启。
- 0.8.0 要求扩展逻辑 ID，而旧官方工具 ZIP 缺少该字段。13 项工具 × 3 个平台已使用新版本上传和正常审核 API 发布。仅增加 `extension.json` 中的逻辑 ID；所有程序、许可证和其他文件逐个比对一致，保留旧版本、旧对象和审核资料。
- 最终 Windows 服务版连接真实商店，解析 jq、生成依赖计划、下载 ZIP、安装、执行 jq、核对只读商店来源、停用均通过。

## 本次验证

- Python 202 项：196 通过，6 项条件跳过；前端 1,210 项：1,208 通过，2 项条件跳过；236 个脚本模块解析通过。
- Windows 两版、Linux 四版均在最终发行物上通过 9 项打包依赖合同，共 54 项，包括启动、九类身份、依赖反查、级联停用、幂等收据、恢复启用、运行中迁移拒绝、错误编辑原子性与重启恢复。
- Android 两版均为正式签名，与旧正式版证书一致；CRC、完整原生依赖闭包、16 KiB ELF/ZIP 对齐通过。完整版 474,036,328 字节，低于安装更新 512 MiB 限制。
- 线上实际 HTTPS 处理器完整下载并核对八个更新对象和八个官网下载文件的大小及 SHA-256。旧语义版本、旧 build-only 请求均得到新版和强制更新标志；掩掉高字节的版本比较结果一致。
- Windows 公网客户端另外完整下载校验七个较小更新文件，核对完整版 APK 的公网 HEAD 大小；11 个网站文本文件逐字节核对。完整版的完整哈希校验在服务端真实 HTTPS 路径完成。
- 商店三个平台共 39 项公开目录与新对象校验通过，旧对象仍存在且哈希未变。

## 现场和边界

线上 `xs.service` 持续运行，无需重启；服务程序和 `xs.json` 哈希未变。网站目录 inode 保留，只原子替换已检查的 19 个文件。账号、会话、计费数据库没有替换或恢复；临时发布管理员已登出并删除，原管理员凭据逐项核对未变。备份和证据保留在私有发布目录。

发行物包含本轮开始前就存在的扩展身份/依赖改造和 `app/xs.json` 几何配置，按准确源码指纹构建；没有将这些其他任务改动合并进本次 release commit。构建前后源码指纹一致，原来的未提交改动和未跟踪测试保持原样。

旧完整门禁中的历史夹具、部分 packed/GUI 检查仍未全部适配。本次不宣称所有历史门禁通过。Android 核心真机验收见此前报告；本次最终 SDK 小修复后未重复真机验收（ADB 无设备），已完成自动检查。大型 Android 工具目录验证耗时仍偏长。未进行付费模型调用、Linux GUI 目视和长时压力测试。

旧 Home 中尚无逻辑 ID 的内置扩展使用设置页“迁移内置扩展身份”显式迁移；修改过的个人扩展需按新规范补全信息，不能静默覆盖。官网发布说明中已列出这项升级操作。

发布校验脚本曾直接访问已经移除的可选 `toolpacks` 字段，发生在目录已成功写入后。改用可选字段比较并完成独立的完整只读复核；没有回滚已成功发布的文件，也没有修改产品或服务代码来处理这个校验脚本问题。

机器可读证据和八个文件精确哈希见 [发布收据](2026-10-30-0.8.0-release.json)。私有运行证据在 `.build/release-0.8.0-20261030/`，线上私有备份在 `/home/xs/mdo-release-0.8.0-20261030/`。

# 会话计划工具改为可选外部范例

按用户最新决定，`mdo.todo` 不再作为内置工具或随包模块提供；其他工具保持现有内置实现，不开展全量解耦。版本沿用当前 0.2.5，本轮未执行线上发布。

## 改动

- 从默认 Home 移除 `modules/tools/builtin_todo.c`，迁至源码目录 `examples/tools/todo.c`；示例模块 ID 改为 `example.todo`。
- 从内置工具目录、内置别名映射及专用工具说明中移除 `mdo.todo`/`TodoWrite`。安装示例后，它作为普通 `source: c` 工具出现。
- 开发者可从设置的工具页导入，也可手动放入 Home 的 `tools` 目录。示例和说明均不进入应用打包目录。
- 保留现有会话计划投影、读取、历史恢复、分支和备份协议。未安装时不向模型提供此工具；不删除旧计划、历史记录或用户自己安装的工具文件。
- 计划相关 QA 明确安装示例，不再依赖产品默认提供。

详细安装方法见 [工具范例说明](../../examples/tools/README.md)。

# 2026-10-25 Agent 工具与 Skill 商店来源范式

版本保持 0.6.0，所有改动在主分支提交，未发布官网或自动更新，平台改动未部署。

- Agent 工具和 Skill 的本机列表及各自商店沿用外部工具的呈现：名称后显示提交者用户名，小字元信息区分别显示作者、版本、许可及版权节选，默认详情展示完整归属信息。提交者来自平台账号 owner，不信任归档自称的 submitter；作者由作品声明提供，旧作品保持原作者信息，缺失信息明确说明。
- 商店安装条目隐藏编辑、导出、再次分享、AI 改进和直接删除，保留启停、检查更新、卸载及源码只读查看；新建和离线导入资源保留原操作。来源依据持久安装收据，即使安装者是提交者、或文件在外部修改过，也不自动解除管理。
- 原生 API 对编辑、删除、Skill 打包导出、用于发布的资源导出及个人 Skill 来源复制执行相同规则，403 拒绝；收据损坏时 503 拒绝无法确认归属的定制操作，原文件保持。Skill 构建器手填商店 ID 同样不能进入写入式改进草稿，只读检查仍可用。
- 作品 manifest 新增可选 author（100 UTF-8 字节）与 copyright（4096 UTF-8 字节），许可保留独立字段。独立投稿表单、便携格式、平台校验、旧数据库迁移、目录/详情、安装收据及详情展示贯通；平台目录使用轻量索引，不在每次请求读取大源文件。
- 旧收据只在作品 ID、owner、slug、版本和 SHA-256 全部匹配时从商店补齐署名，不修改资源文件或不可变版本摘要，不借用新版本的署名。返回本机选项卡时刷新元数据。
- 共用列表/详情无内层纵向滚动，底部分页，搜索/来源/状态变化复位页码；沿用统一下载入口。所有单选下拉框采用末端 36px 留白及内缩箭头，多选列表和强制对比模式保留原生表现。

38 项前端行为测试、20 项前端契约和 223 模块解析通过。真实客户端与平台夹具验证：私有投稿、审核、两类目录、用户名与声明作者区分、伪造 submitter 无效、安装/调用/注册、编辑/删除/复制/导出拒绝、启停/更新/卸载、损坏收据保护、旧收据补齐和错误摘要拒绝补齐、升级冲突、版权索引回填及重复启动。没有生产账号、真实模型调用或线上作品写入。

浏览器验证两类本机及商店页面、只读菜单、版权详情、分页、无内层滚动、常规设置页下拉框和 390px 窄屏，未发现脚本错误。隔离服务与证据位于 `.build/resource-store-pattern-20261025/` 及 `D:/GIT/home/.build/mdo-resource-pattern-qa/`。

后续其他扩展类型应遵循的界面、来源权限、署名及下载入口规则已写入 `docs/extension-browser.md`；本轮没有将其余类型逐一改造。构建摘要在体验包完成后补充，Android 尚未做真机回归。

## 交付

- 九类资源：Agent、SubAgent、工具、Skill、MCP、命令、扩展包（C 模块）、扩展工具包（命令行）和 mdo 插件（客户端 VFS）；组合包为分发形式。
- 匿名浏览、个人投稿与私人版本隔离；管理员审核、退回、下架及作者撤回；审核决定与版本 SHA-256、修订及操作者同事务记录。
- 客户端资源导出、草稿、直接安装、检查更新、离线导入和卸载；本地管理不再依赖网站登录。
- 文件计划、计划哈希确认、平台／构建号和代码信任检查；失败恢复文件、插件配置和安装登记；卸载保留用户改过的资源。
- 命令行程序清单和使用说明注入 Agent；不可变插件修订挂载 VFS，冲突检测和运行时重载入口。
- 附属文本安全预览、二进制下载及 SHA-256；修复大包下载发送队列截断和客户端旧导出响应上限。

格式及首版边界见 [九体系生态商店](../ecosystem-v2.md)。新格式 JSON 6 MiB、附属文件合计 4 MiB、单文件 1 MiB。
大型外部归档、跨包依赖自动解析、离线签名校验和网站向指定设备推送尚未交付；大型官方工具包继续使用原 XRTPACK 通道。

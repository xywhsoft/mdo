## 本轮变更

- 自动恢复重试次数可配置，默认 10 次；对应步骤成功后清零。
- 暂时故障耗尽重试后保留任务、等待自动恢复，移除隐藏的十五分钟恢复总窗口。

- MCP 暂时不可用不再阻断普通任务，保留身份范围，后台重连并通过公共警告入口报告。
- C Agent 与插件提供明确的安全重试返回值，可选观察器错误隔离。
- 权限确认默认等待用户，支持取消及明确截止；修复 ask 四小时等待常量溢出。

# 设置操作栏归属右侧内容区域

- 将保存状态、恢复默认、放弃更改和保存设置整体移入设置内容列。桌面导航跨越内容与操作栏两行，独立使用完整可用高度；右侧内容独立滚动，底部操作栏固定。
- 手机使用分类选择器、内容、操作栏三行布局；聚焦纠错滚动改为仅调整实际内容滚动区，避免输入框被底部按钮遮住。未改动设置保存、错误重试、放弃或恢复默认逻辑。
- 浏览器加载真实设置 HTML 和样式，通过隔离设置快照验证：1442×900 下导航高度／scrollHeight 均为 842，没有额外滚动；操作栏左边缘 210、顶部 838、底部 900，与右侧内容列对齐。390×844、DPR 3 下无横向溢出，三项操作按钮完整可见且在同一行，操作栏位于内容区下方。
- 软键盘模拟 250px 可视高度回归通过：空闲状态隐藏操作栏，编辑状态操作栏底边 250，恢复默认按钮单独显示，高度 49；收起键盘后恢复三个操作按钮。
- 验证：7 项设置页面测试、20 项前端契约测试、226 个前端模块解析通过；本轮新增回归覆盖移动端聚焦时仅滚动内容，不滚动导航和底栏。

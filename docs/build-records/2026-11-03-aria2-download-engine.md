## 行为

下载中心自动检测已安装、启用且校验/授权有效的官方 `external-tool:mdo.aria2`。可用时按需启动隐藏的独立 aria2 子进程，以私有回环 RPC 驱动下载；不可用时使用内置下载。启动、RPC、进程和可回退的传输失败在同一任务内切换一次内置引擎。认证、磁盘、校验失败及用户取消直接报告，不通过换引擎重复请求。

暂停、继续、重启恢复、取消、清理和安装均沿用原生任务身份。两个引擎使用独立临时文件；回退前停止 aria2 并清理它的文件，不根据分块文件长度推断连续前缀。mdo 统一执行最终大小/SHA-256 校验，扩展仍需通过封存与显式安装流程。

下载窗口展示引擎及回退提示，包含中、英、俄三种语言。aria2 最多使用四条连接；未知长度的 chunked 响应可能单连接传输。未增加任意 URL 或 HF/模型权重入口，也未提高既有资源上限。实现见 [下载中心说明](../download-center.md)。

账号授权头只通过内存 RPC 传递，不写命令行、会话文件或工具配置；日志只记录引擎阶段和数字错误码。工具文件在进程退出前保持租约，完成/取消停止子进程，宿主异常退出使用 aria2 的父进程检测。

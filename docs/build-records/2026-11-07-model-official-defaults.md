- 参数解析保留目录 `request_defaults`，和供应商返回的能力字段分开；API 能力仍优先。已有模型重新识别时，即使 API 返回完整能力字段，也读取目录预算。

- 中文、英文、俄文提供预算依据和操作说明；服务端字段对旧目录客户端兼容。

未知模型草稿仍用 8K 暂存，但缺少必要能力时不能直接保存。服务端参数更新不能改变旧客户端的预算生成算法。配套客户端源码已完成，**本次未发布客户端安装包、未变更客户端版本和正式发布指针**；已保存的 8K 需要升级客户端后，重新识别并主动点击“使用推荐预算”再保存和验证。

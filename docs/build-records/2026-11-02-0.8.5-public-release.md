# mdo 0.8.5 正式发布

2026-11-02 22:27:26（UTC+8）完成官网下载和八条自动更新渠道切换。
显示版本为 `0.8.5`，语义版本码为 `05000805`，更新目录修订为 36，
全部渠道延续强制更新。官网：<https://mdo.xywhsoft.com/download/>。

## 发布内容

- 默认提供 C Agent 工具 `todo`，支持完整待办更新、进度和清空，保留旧 `mdo.todo` 历史读取。
- 修复活动运行期间重复设置 MCP 范围，导致尚未请求模型就中断的问题。
- 会话按最后激活时间排序，完善 Computer Use 能力提示和自动准备。
- 历史分页读取容错，避免局部损坏或超大记录影响整个会话。
- mdo 管理的持久化路径使用 Home 相对路径；旧绝对路径失效时兼容迁移后的 Home。
  外部项目目录及模型工具的工作区相对参数不改变。
- Android 完整版只预置 BusyBox、curl、jq、OpenSSH、aria2、ripgrep、7-Zip、Python
  八项原有工具。源码下载继续停用。

## 验证与生产保护

- 六个最终可执行文件分别通过九项扩展依赖打包合同，共 54 项。
- Windows 最终包通过 12 项 Todo 端到端合同、12 项原生 Todo 合同、8 项默认目录合同，
  以及 7 项实际复制 Home 后的运行检查。
- 版本编码 5 项、静态合同 127 项、Android 路径别名 9 项均通过；更新运行时检查通过。
- 两个最终 APK 通过 CRC、版本和编号、依赖闭包、16 KiB ELF/ZIP 对齐、
  原有八项工具清单和正式证书校验。发布准备器核对全部八个产物。
- 服务器预检和发布后校验通过；公共 HTTPS 完整下载八项官网文件及八项更新对象，
  字节数和 SHA-256 全部一致。核对旧客户端、仅安装编号、最高版本字节归一化和同版本重打包响应。
- 官网三种语言的版本、安装编号、文件体积、下载链接、哈希提示及发布说明同步更新。
- 独立 Windows 客户端核对八项更新响应和八项官网下载 HEAD，完整下载 Windows
  图形版与 Android 精简版，SHA-256 均一致。
- 服务 PID、`xs` 和 `xs.json` 哈希不变，未重启服务；模型配置、通知和已有生态内容保持原值。
  账号、会话、计费数据保留；临时管理凭据已清理，原管理员凭据不变。

上传使用现有 rsync 和 SSH 做增量传输，暂存完整文件后仍重新核对哈希；
没有原地修改在线文件。官网按文件原子替换，目录 inode 保留，旧文件和目录清单保存在服务器私有备份。

本机独立下载复核初期多次出现传输中断，直连与系统代理均有失败收据；后续 Windows
原生 curl 完整下载 EXE（14.06 秒）及精简 APK（4.59 秒）均成功。服务器端以 1 MiB/s
限速下载完整版 APK 持续 81.16 秒，同样完整成功。保留网络失败记录，未确认中断根因，
没有据此改动生产网络配置或声称永久解决该链路问题。

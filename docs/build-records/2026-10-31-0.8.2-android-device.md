### 通用助手

两版均实际通过主 Agent 委派到原生子 Agent，执行写入→命令→读取→最终报告。校验模型路由、思考档位和输出额度继承、项目规则注入、独立上下文不复制父会话私有消息、子任务不再次委派。

前台、后台、只读、子任务 HTTP 失败、取消以及运行中切桌面再回前台，共六种场景均到达预期终态。只读任务只批准本次 `agent_delegation`，子任务未获得写入或执行能力；子任务失败没有终止父会话。切后台时保留正在执行的真实子任务，回前台 PID 未变。

验证冷启动、用户编辑保留、停用状态保留、过期指纹拒绝恢复、显式恢复内置原始字节但保留停用状态、重新启用，以及卸载后重启不自动复活。精简版明确卸载助手后原位升级完整版，助手仍保持未安装；后续测试通过显式创建本地角色并恢复内置文件、启用来继续，没有绕过用户卸载选择。

### SDK、进程与目录

验证短 stdout/stderr 与退出码、空 argv、长输出完整文件与分页、显式输出位置不覆盖已有文件、输出限额、超时保留部分结果、启动失败原因链、stderr 合并和流事件。原生 `exec/spawn/status/wait/stop/read` 跑通，后台输出无需收割且结果别名只读。冷重启后输出文件哈希保持一致。

九类目录的稳定身份、深层知识库文件写入读取、过期修订拒绝、启停、整目录卸载和 ARM64 TCC 编辑器命令调用 Application SDK 均通过。

### 完整版原始八种外部工具

BusyBox、curl、jq、OpenSSH、aria2、ripgrep、7-Zip、Python 均通过 APK UID 经公共转发目录实际执行。Python 的 ssl/sqlite3、长 stdout/stderr、停用时移除环境变量、重新启用恢复均通过；ripgrep 停启与绑定恢复正常。工具绑定冲突测试保留未知用户文件，拒绝跨包或不规范路径的链接，恢复原条目后命令索引正常。

### 原生界面

独立 QA WebView 注册了真实 UI 客户端，SDK `ui.settings` 动作由客户端确认成功。仅连接该 QA PID 的调试 socket，打开实际 SubAgent 页面和“恢复默认”公共弹窗，未提交恢复动作。

实际视口为 361×710 CSS 像素，DPR=3.5；窗口宽约 337.14 CSS 像素，位于视口内，无横向溢出。取消和恢复默认按钮位于独立 footer，footer 不在滚动内容区中。

当前 QA 进程没有崩溃或 ANR 证据；最终诊断列表为空。这里只验证上述场景，没有将其表述为所有 Android 设备、系统省电策略或真实供应商网络均已覆盖。

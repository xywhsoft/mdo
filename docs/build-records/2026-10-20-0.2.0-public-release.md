## 上线与边界

服务器备份保留在 `/home/xs/mdo-release-0.2.0-20261020-30000102/backup`。通过受 CSRF 和目录修订保护的正式管理接口发布；临时发布凭据已删除，原管理员凭据未变。原 `/opt/www/xs`、`xs.json`、宿主 PID 均保持原值，未重启模型或网站服务。现有账号、会话及计费数据保留。

# Git 缺失时不显示文件变更

补齐上一轮遗漏：除了非 Git 目录，设备上未安装/无法找到 Git 时也直接隐藏自动变更区域，不显示“变更暂不可用”，不触发会话恢复。

只有进程启动报告未找到 Git、且工作目录仍然存在时，才归类为 `git_unavailable`。工作区丢失、权限问题、损坏或超限的快照保留原有错误。已有有效收据在 Git 被移除后同样安静隐藏；旧错误收据也按当前可验证的 Git 可用性处理，不补造历史比较。

原生回归临时移除 PATH，验证缺少 Git 时的真实进程错误、已有收据读取及工作区丢失的区分；随后恢复测试进程原 PATH。真实 Chromium 回归在中/英/俄及桌面/窄屏下验证缺少 Git 的区域保持隐藏，不进行重试。继续使用 0.9.2 本地测试包，不发布。

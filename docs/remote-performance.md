# 会话加载和远控性能

## 已实现

- 本机和远控使用同一个 `/conversation` 显示快照接口。首次读取最近四轮；向上滚动时读取更早内容。导航索引单独分页，不必先下载整段历史。
- 文本流片段在服务端合并为显示节点。单次保留最多 96 个节点、约 96 KiB 投影预算；单次扫描最多 16 MiB。单条长文本预览最多 8 KiB，其余通过“读取完整内容”按需读取。原始会话和模型上下文不被裁剪。
- 页面内 LRU 保留最多八个会话视图，桌面预算 24 MiB、Android 12 MiB；单视图最多 4 MiB。返回已缓存会话先显示内容，再按游标校验新增内容，并恢复滚动和折叠状态。缓存不另建数据库，退出、账号/设备变化和运行代变化会失效。
- 每个投影有会话代 `epoch`、节点 ID、内容 SHA-256；节点 ID 由会话 ID、文件代和事件 ID 组成。原始字节快照还带整体摘要，浏览器验证后才更新视图。会话日志被替换时重新取最近内容，不把新旧历史拼接起来；历史页不能倒退实时游标。
- 同步、历史加载、失败及重试有可见提示。切换会话取消旧读取；响应即使忽略取消，也不能覆盖新的选择。写请求及当前会话读取优先于排队的更早历史。
- 远控下载协商最高 256 KiB 窗口，仍在实际消费正文后确认。旧端保持 64 KiB 行为。目标输出队列仍有界，不把整份文件置于传输队列。
- 历史 JSON 在 32–256 KiB 时尝试 gzip level 1，仅压缩收益超过 10% 时发送。普通 HTTP 由浏览器解压，远控合成 Response 由 DecompressionStream 解压；长度/完整性校验及解压后上限保留。没有引入额外 JS 压缩库。
- 同账号的已授权设备可在局域网使用原生 TLS + WebSocket 直连。服务器连接先可用，直连在后台探测；失败继续中转。设备菜单和远控设置显示当前连接方式。实时订阅迁移连接时按原游标恢复。

这些改动减少首屏正文和网络往返，并不保证公网远控与本机具有相同延迟。尚未引入完整 DOM 虚拟列表；按需读过的历史会在当前视图中保留。

## 直连边界

目标只有在明确开启远控且账号授权有效时创建独立的临时 TLS 监听。普通业务 HTTP 继续使用回环地址。监听仅处理 `/mdo-lan`，不直接开放项目、文件或设置路由。

直连信息通过已有认证中继传递：最多四个私网 IPv4 地址、临时端口、临时 CA 证书、绑定 peer 的 60 秒单次握手令牌。服务端证书与 CA 分离，使用 xrt 的 P-256/ECDSA 和标准 TLS 证书链验证。密钥、证书、地址及令牌只保存在内存，不安装系统信任根，也不写配置。

浏览器和 Android WebView 仅连接本机 `/api/v1/connector/direct`；它要求页面 Origin、当前写入令牌和本机登录。原生网关验证私网地址与证书，再建立目标连接。账号、只读/控制权限、运行代、业务写入令牌和写入去重继续沿用原链路，不允许握手改变权限。

每个请求和订阅固定在受理时的链路上；探测完成不会将正在传输的正文切到另一条链路。直连断开只终止该链路的在途操作，随后新请求走中转。已发出且结果未知的写入显示未确认，绝不在中转上自动重做。注销、撤销、关闭远控或中继授权连接断开时关闭对应直连。

当前仅支持可达的私网 IPv4。跨公网、隔离 Wi-Fi、VPN 或防火墙不通时使用中转。不包含 NAT 穿透、IPv6 直连、WebRTC、DataChannel 或独立网站控制端。Windows 防火墙和 Android 的后台限制仍可能影响可达性。

## 构建与验证

精简宿主增加 DEFLATE、P-256 密钥生成/签名和网卡枚举模块；TCC 通过现有 xs 公共符号接口访问。无需更新网站中继协议或部署服务器代码。

本次完成有界功能测试，不进行压力或高负载测试：

- 69 项 Node 测试：快照/所有权/摘要、缓存、历史和实时重叠、会话替换、迟到响应、取消、传输窗口、gzip 完整性、直连链路隔离和写入不重放。
- 20 项前端契约测试；C11 `-Wall -Wextra -Werror` 编译检查。
- 原生 xs/TCC 的真实本地网站与中继夹具：历史 gzip、协商窗口、账号隔离、撤销、重连、Unit 回收；局域网 TLS 证书链、错误信任材料/握手令牌、只读权限、HTTP/live/receipt 转发、九次顺序订阅关闭和中转回退。
- Windows 单文件包默认 Agent/工具目录启动检查。

一个四轮历史夹具的首屏 JSON 为 43,145 字节，gzip 后为 2,089 字节。它是单个功能样本，不代表所有会话的压缩率或真实网络延迟。

直连测试在同一台电脑的两个真实原生端之间使用回环地址，验证了认证、TLS、业务链路与回收，尚未完成两台物理设备之间的延迟对比，也未完成新 APK 的手机实测。Android 构建、签名和对齐验证不能代替上述实机验证。

主要回归入口：`test_conversation_snapshot.mjs`、`test_remote_transport_performance.mjs`、`test_conversation_runtime.py`、`test_remote_bridge.py`、`test_remote_lan.py`。实现入口：`sessions/conversation_page.inc.c`、`features/chat/timeline-store.js`、`api/remote-transport.js`、`remote/lan.c`。

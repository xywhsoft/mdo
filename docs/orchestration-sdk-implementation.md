# 编排 SDK 实施记录

目标：通过同一套公开 SDK 支持配置式/C Agent、SubAgent、命令、工具和插件的持续编排，复用现有受管会话、模型、工具、任务、队列及扩展生命周期。产品保持 0.7.0，本项工作不隐含客户端正式发布或生产服务更新。

## 实施目标与验收

| 目标 | 内容 | 状态 |
| --- | --- | --- |
| 调用与结果契约 | 不可变调用链、明确结果、能力发现、C/RPC 同一语义 | 调用链、结果及按代码代际的能力预检完成 |
| 持久状态 | 有界原子事务、CAS、删除后修订、租约与旧执行者拒绝 | 原子状态、幂等回执及带 fence 的租约完成 |
| 邮箱与事件 | 持久消息、去重及确认、通知等待、缺口与背压 | 完成；后续接入成员投递 |
| 角色生命周期 | 通用回调、运行结束/取消/压缩与实际子任务完成 | 运行及压缩通知完成；输入、空闲与恢复接线待完成 |
| 持续实例 | 多轮成员、持久身份、安全入账、取消及重启恢复 | 待完成 |
| 额度与调度 | 执行树预算、并发准入、取消继承、公平与背压 | 待完成 |
| 续跑与恢复 | 有界唤醒、无进展检测、检查点、效果不确定时不重放 | 待完成 |
| 路由与工作流 | 类别选择、候选链、依赖、原子认领、验证证据 | 待完成 |
| 团队与工作区 | 成员/共享任务/退出、执行目录归属与冲突 | 待完成 |
| 开发者支持 | 公共头、发现契约、配置接线、诊断和故障注入范例 | 待完成 |

每个功能目标或修复单独提交 master。测试使用隔离 Home 和回环模型，保留用户 `app/xs.json` 及其他任务的未提交修改。

重要边界：SDK 异步 operation 是受理回执，不是长期成员；事件环形日志不是持久邮箱；工具失败不是整个工作失败；委派工具返回不代表后台子任务完成；不确定的外部效果不会自动重放；用户取消/审批/恢复确认不能被插件续跑绕过。受信任的进程内 C 代码没有进程沙箱。

## 已实现：调用链与结果

`sdk.context` 增加宿主生成的 `trace_id/call_id/parent_call_id`；同步嵌套与异步 operation 继承同一 trace，单次调用各有身份，HTTP 自报 trace 不生效。公共 `mdo/execution.h` 提供结果分类，保留 uncertain、cancelled、timed_out、limited 的区别；operation 保留旧 state 并追加 outcome。

事件带调用链，读取按条数及 32 KiB 正文预算分页；cursor 只推进到实际消费位置。`events.emit` 限制 8 KiB 数据，原生超大通知仅留省略标志，避免命令 64 KiB 结果上限被整个环形日志挤爆。

验证：`tests/test_orchestration_sdk_runtime.py` 使用真实 TCC 模块与 HTTP，核对嵌套及后台调用链、明确错误、事件多页顺序与大载荷拒绝。原有 SDK 真实运行测试和目录契约同时回归。

## 已实现：原子状态

`state.get/list/put/compare_exchange/remove/transaction/receipt.get` 对当前项目及显式/扩展默认 namespace 操作；`mdo/state.h` 为 C 提供同一服务封装。写入必须提交 `expected_revision`，同一事务所有检查通过后，以一份校验摘要保护的原子文档发布。删除保留修订，避免删除后重建接受旧写入。

可选 `request_id` 与请求规范摘要、结果一并提交；重试返回原结果，内容不同返回冲突，重启后仍有效。命名空间最多保留 128 个请求回执，容量到达上限时拒绝新增而不驱逐去重证据；长任务使用独立执行命名空间。单值 16 KiB、每事务 64 次写入、每空间 1024 个含 tombstone 的键/4 MiB、最多 256 个空间文件。列表只返回元数据并可固定 namespace revision。

真实 TCC/API 回归覆盖 C 便捷函数、8 个竞争写入者、失败事务零发布、同事务相同修订、删除重建、空值/布尔值、非法路径、大小限制、跨空间隔离、持久回执和重启后数据损坏拒绝。损坏或未知版本不被空白状态覆盖。

## 已实现：租约与 fencing

`lease.acquire/inspect/validate/renew/release` 复用同一原子状态文档。租约拥有宿主进程 epoch、随机 token、单调递增 fence 与单调时钟到期值；重启后旧租约失效，重新获取得到更高 fence。更新与释放均要求当前有效 token/fence，过期后不能续约复活。

`state.*` 写入可提交 `lease_guard:{id,fence,token}`，在同一事务锁内检查租约并提交状态，拒绝旧成员的迟到结果。单独 `lease.validate` 不能保护后续任意外部程序的效果。系统记录前缀 `sys.` 不允许通过普通状态写入修改；查询租约不返回 token。

租约变更必须带 request_id，重试返回原始受理结果，不延长租约。回执不表示租约此刻仍有效；调用者应在受保护的状态写入中使用 lease_guard。TTL 为 1..300000 ms。回归验证互斥、释放后拒绝旧 fence、到期续约拒绝、重启失效和 fence 延续。

## 已实现：事件等待

`events.wait` 支持 topic、epoch、after、limit 和最长 60 秒等待；沿用有界分页与缺口报告。宿主使用条件变量并在睡眠前重新检查序列，避免读取与等待之间漏掉通知。匹配事件立即唤醒，超时返回空页，取消/调用截止时间返回明确结果，退出时广播并排空等待者。等待接口自身不发 service.before/after 通知，避免等自己的事件。

回归通过后台异步等待与发送竞争、按主题唤醒、超时空页、旧 epoch 立即提示重同步和运行中取消。

## 已实现：可靠邮箱

`mailbox.send/get/read/ack/wait` 与 `mdo/mailbox.h` 共享原子状态存储。message_id 对同一邮箱的规范化内容/发送者去重；相同 ID 不同内容拒绝。sender 来自受管调用上下文，不采用正文自报身份。读取不消费，ack 可与 checks/writes、lease_guard 在同一事务中提交；失败时保留待处理消息，重复 ack 不再执行状态写入。确认后丢弃正文，保留去重与确认回执。

每条正文最多 8 KiB，单收件人最多 128 条未读/256 KiB 未读正文。读取按游标及 32 KiB 页预算分页；未来游标提示 resync。消息和状态共用每执行命名空间 1024 个保留记录限制，到限拒绝而不静默丢弃。等待通过事件唤醒并定期核对持久状态，通知不是消息的唯一证据。

回归验证 C 包装、规范化去重、重启后待处理消息、ack 与状态修改原子性、重复确认、确认后发送重试、分页顺序、等待唤醒及未读背压。模型账本投递会在持续实例阶段结合原有队列幂等身份接入，本阶段不将手工 ack 宣称为任意外部效果恰好执行一次。

## 已实现：全局角色生命周期

公共 `mdo/lifecycle.h` 与 `Registrar.AddLifecycle` 允许仅提供生命周期功能的独立 C 模块。按角色模式、阶段掩码和稳定优先级注册，适用于配置角色与 C 角色。回调固定到会话的模块 catalog，执行时不持有模块目录锁；角色回调内的 SDK 调用也固定同一代码代际。

新增运行准备、开始、完成、失败、取消、压缩开始/完成/拒绝、子角色接受与实际完成阶段。准备阶段支持显式控制拒绝，观察者错误发出 extension.warning 并隔离。运行完成通知在结果与错误完整返回后执行；`OutcomeAvailable/Outcome/Error` 明确运行结果，`mdoAgentEvent` 提供有界生命周期元数据。结束阶段不再允许用回调错误撤销已发生效果。

受管默认循环与 C Run 使用相同包裹层。活动运行栈按实际执行线程及嵌套顺序绑定回调，不通过工作目录猜测实例。后台子角色可在父角色结束后独立发布完成通知，旧 AFTER_DELEGATE 保留工具返回语义。压缩阶段提供运行时观察通知。

`test_lifecycle_runtime.py`（含 --background）验证全局上下文修改、配置角色、结果物化时机、实际子角色完成、可选观察者失败隔离、控制拒绝及旧/新 generation。已有角色上下文、29 项创作检查和 6 项 C11/C++17 头契约回归通过。输入、真正空闲后的续跑及恢复钩子将在持久成员/调度接线时补齐；当前不将这些阶段宣称为已完成。

## 已实现：能力发现与预检

`sdk.capabilities` 仅声明实际已实现的 feature 版本及资源限额；`sdk.require` 按服务、原生函数和 feature 版本返回 satisfied/missing，供配置角色及 C/RPC 客户端在执行前检查。预检只读，不授予权限，也不代替实际资源准入。公共 `mdo/capabilities.h` 使用同一服务。

修复热重载时目录错代：`sdk.services/describe/require` 与实际调用使用同一 retained catalog。真实异步 provider 在重载后查询仍看到原代码描述，而新调用看到新描述；未知服务/原生函数/未实现 feature、版本不足及非法版本都通过回归。

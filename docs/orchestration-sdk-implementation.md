# 简化的 Agent 协作 SDK 实施记录

本轮以完成实际任务、简化配置/C 扩展开发为目标。产品保持 0.7.0；不隐含正式客户端发布或生产部署。每项功能/修复独立提交 master，保留其他任务的工作区改动。

## 收敛后的范围

| 内容 | 实施方式 | 状态 |
| --- | --- | --- |
| 角色运行与扩展回调 | 配置/C 角色共用运行机制及公开生命周期回调 | 已有 |
| 多轮成员 | 创建、发消息、执行、取结果、等待、取消、关闭 | 创建/发送/单轮执行已有，补结果与等待 |
| 中断恢复 | 保留会话，明确继续或结束；不重放结果不确定的工具 | 补齐中 |
| 共享状态和消息 | 原子状态、可靠邮箱、事件等待 | 已有 |
| 任务协作 | 简单任务列表、依赖、原子领取、提交结果 | 补齐中 |
| 简单接入 | 公共 C 便捷接口、配置角色可用的范例工具、使用说明 | 补齐中 |

不新增调用链追踪、诊断面板、能力检测/预检体系、运行监控、独立工作流引擎、团队/调度平台。模型选择、工作目录、工具/权限、进程执行及后台调度复用既有能力。必要的取消、并发上限、幂等回执、原子保存和恢复检查保留在内部。

已移除本轮新增的 trace/call/parent 追踪字段、sdk.capabilities/sdk.require 及专属公共头。保留既有 sdk.services/describe：这是扩展调用和编辑器集成已有的接口目录。目录和调用继续绑定同一代码代际。成员下次执行直接采用当前角色代码，取消全目录源摘要门和手动 rebind 步骤；已开始的执行仍固定原 catalog。

## 已有可用能力

- `state.get/list/put/compare_exchange/remove/transaction/receipt.get`：按项目/namespace 保存，写入需 expected_revision；删除保留修订，避免迟到写入覆盖重建值。同事务一次原子发布，request_id 可用于幂等重试。单值 16 KiB、事务最多 64 次写入、每空间 1024 记录/4 MiB/128 份请求回执，容量满时明确拒绝，不悄悄删除去重信息。
- `lease.acquire/inspect/validate/renew/release`：同一状态中的限时锁，旧持有者通过 fence/token 被拒绝。`lease_guard` 与状态写入在同一锁内验证；单独验证不能保护后续任意 OS 副作用。
- `mailbox.send/get/read/ack/wait`：消息 ID 去重、读取不消费，确认与状态写入可以原子提交。每条正文 8 KiB、收件人 128 条/256 KiB 未读限额。确认后保留去重回执。事件只负责唤醒，消息以持久数据为准。
- `events.read/wait/emit`：有界订阅/通知，取消和调用期限有效。8 KiB 事件、32 KiB 分页，重启/环形缓冲覆盖时明确告知重读真实状态。
- `instance.create/get/list/send/step/cancel/close`：私有原生多轮会话，不占用户会话列表。创建/排队不调用模型，step 处理一条消息并保存。每空间最多 64 个成员，全局最多 8 个成员同时执行。operation.start 可异步调用 step。
- `mdo/lifecycle.h`：插件可介入配置/C 角色上下文、请求、工具、委派和运行结束。结束回调在结果完整后发生，后台子任务完成独立通知；观察者失败不会撤销已完成工作。

成员继承父会话的实时权限。父运行退出后仍保留共享 scope；重新打开父会话继续复用，“询问/完全访问”即时切换。退出先取消并排空成员，随后销毁依赖服务。不确定外部效果不自动重放，审批与用户取消不能被自动续跑绕过。受信任进程内 C 扩展没有进程沙箱。

## 验证方式

真实 TCC/HTTP 隔离 Home 测试：`test_orchestration_sdk_runtime.py` 覆盖原子状态、竞争写入、回执、锁、邮箱、等待及重启；`test_member_sdk_runtime.py` 使用离线模型，覆盖多轮历史、重启、热重载、关闭、权限共享和中途退出不重放；`test_lifecycle_runtime.py`（含 --background）覆盖配置/C 角色、真实子任务完成、回调隔离与代码代际。运行必要回归即可，不为产品增加诊断体系。

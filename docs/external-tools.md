# 外部工具（0.3.0）

Agent 工具仍是模型直接调用的结构化接口。外部工具是登记的命令行程序，沿用 exec/spawn 或 SDK 进程执行。外部工具不做系统扫描、版本探测或运行测试。注册时验证文件存在；每次构造请求只注入启用且路径仍存在的条目及其使用说明。未登记程序仍可按原有执行权限尝试。

外部工具页只有“本机工具”和“工具商店”。本机负责添加、编辑、启停、卸载和分享；商店负责浏览、下载和更新。下载任务独立于页面生命周期。推荐仅在主界面首次提示；部署过、已选择安装或不再提示之后，不会因卸载、停用、替换或后续推荐变化再次推荐。

本机路径不进入平台发布清单。分发文件使用相对路径，安装后生成本机入口。分享单个程序时只读取选定文件；需要 DLL、标准库等附属文件时，用户明确指定分发目录。平台投稿绑定作者、版本、平台、程序 SHA-256，管理员审核后公开。所有公开工具使用相同商店列表，没有官方专区或特殊排序。

Windows/Linux 可分别安装和更新；Android 下载行为转换为 full APK 安装/升级，full 内置条目可单独启停和修改说明，不能独立删除其程序文件。旧 core/python 收据迁移为独立条目，不重新下载、不删除共享目录；手动接入和迁移条目卸载只移除登记。

数据包是 `MDOCLI1\n` + 4 字节小端 JSON 长度 + 清单 JSON + 按清单顺序排列的文件字节。复用 xrt 文件、SHA-256、HTTP 和现有平台身份/审核能力，没有安装脚本。清单至多 1 MiB、4096 文件，完整文件载荷至多 512 MiB；每个文件有路径、大小、SHA-256 与 0644/0755 权限。拒绝重复或跨平台别名、路径越界和入口缺失。下载、逐文件校验和部署完成后才原子发布登记；失败保留旧版本。安装不执行任何工具探测。

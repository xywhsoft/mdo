# 外部工具（0.3.0）

Agent 工具仍是模型直接调用的结构化接口。外部工具是登记的命令行程序，沿用 exec/spawn 或 SDK 进程执行。外部工具不做系统扫描、版本探测或运行测试。注册时验证文件存在；每次构造请求只注入启用且路径仍存在的条目及其使用说明。未登记程序仍可按原有执行权限尝试。

外部工具页只有“本机工具”和“工具商店”。本机负责添加、编辑、启停、卸载和分享；商店负责浏览、下载和更新。下载任务独立于页面生命周期。推荐仅在主界面首次提示；部署过、已选择安装或不再提示之后，不会因卸载、停用、替换或后续推荐变化再次推荐。

本机路径不进入平台发布清单。分发文件使用相对路径，安装后生成本机入口。分享单个程序时只读取选定文件；需要 DLL、标准库等附属文件时，用户明确指定分发目录。平台投稿绑定作者、版本、平台、程序 SHA-256，管理员审核后公开。所有公开工具使用相同商店列表，没有官方专区或特殊排序。

Windows/Linux 可分别安装和更新；Android 下载行为转换为 full APK 安装/升级，full 内置条目可单独启停和修改说明，不能独立删除其程序文件。旧 core/python 收据迁移为独立条目，不重新下载、不删除共享目录；手动接入和迁移条目卸载只移除登记。

数据包是 `MDOCLI1\n` + 4 字节小端 JSON 长度 + 清单 JSON + 按清单顺序排列的文件字节。复用 xrt 文件、SHA-256、HTTP 和现有平台身份/审核能力，没有安装脚本。清单至多 1 MiB、4096 文件，完整文件载荷至多 512 MiB；每个文件有路径、大小、SHA-256 与 0644/0755 权限。拒绝重复或跨平台别名、路径越界和入口缺失。下载、逐文件校验和部署完成后才原子发布登记；失败保留旧版本。安装不执行任何工具探测。

## 描述与模型提示词

`description` 面向用户，说明工具的用途。客户端本机列表、商店、网页商店和创作中心显示、检索此字段；`prompt` 面向模型，说明何时使用、如何调用及注意事项，只用于模型环境注入及详情页中明确标识的使用提示。两个字段分别保存、分享、审核和下载，不互相覆盖。

新界面创建或编辑工具时分别填写描述和提示词。描述最多 512 个字符，原生 API 和归档限制为 2048 UTF-8 字节；提示词仍最多 16384 UTF-8 字节。`MDOCLI1` 清单携带两个独立字段，例如：

```json
{
  "description": "提取 PDF 文字和图片，并将页面转换为图片。",
  "prompt": "需要读取 PDF 时使用 pdftotext；需要渲染页面时使用 pdftoppm，并逐项传入文件路径。"
}
```

旧记录和旧归档允许缺少 `description`：未知第三方条目显示“暂无描述”，不会复制提示词。官方条目按固定工具标识补充预先编写的描述；已有描述会保留。旧客户端编辑时省略字段，不会清除已保存的描述。平台数据库增加默认空字符串的描述列，保留安装文件摘要、审核状态和计费数据；仅对缺少描述的官方条目填入独立说明。带有非空描述的新归档安装时校验目录元数据与清单一致，失败仍保留旧版本。

## 可迁移的命令入口

Windows、Linux 的统一入口为 `<Home>/data/cli-tools/bin`。mdo 只在自身进程及子进程的 PATH 前面加入这个目录，不写系统或用户环境变量。SDK `process.run`、Agent `exec/spawn`、子程序启动的后续命令都可使用登记的命令名。

Windows 通用转发器使用锁定版本的 xrt 构建，约 310 KiB，仅依赖系统 DLL。构建时内置到 Windows 产品 VFS 的 `generated/native/windows/cli-forwarder.exe`；使用时按名称生成 `rg.exe`、`python.exe` 等入口，优先使用硬链接，文件系统不支持时复制。母本位于 `data/cli-tools/forwarders/<SHA-256>.exe`。按自身文件名读取同级上层的 `state.json`，其中 `commands` 字段将名称映射到 **Home 相对路径**及固定前置参数。转发不经过 shell，保留空参数、Unicode、引号、输入输出管道、当前工作目录和退出码；支持 Ctrl+C，并在转发器被终止时清理其子进程树。注册表有字节数、深度、命令数和参数数限制，拒绝路径越界与循环转发。

Linux 使用可执行 `/bin/sh` 包装脚本，最终 `exec` 真正的入口路径。这样工具包原有脚本仍能根据自身 `$0` 找到加载器、动态库、Python 标准库。参数逐个引用，保留空参数和特殊字符。不直接把依赖自身脚本位置的入口做成软链接。

安装、更新、启停、编辑、卸载和启动恢复会同步命令入口。Windows 以同一次原子写入发布工具登记及转发索引；Linux 单个脚本原子替换，登记保存失败会恢复此前脚本。新旧 Linux 命令集合切换期间不承诺所有命令同时切换。未知文件或命令重名会拒绝操作，并保留原文件与旧登记。运行中的旧版本文件保留至重启清理；新调用使用新映射。工具页显示实际导出的命令名和统一目录。

自定义工具可设置一个命令名及多个别名。Home 内的程序以相对路径保存，移动 Home 后重建本机路径；Home 外的程序保留绝对路径，继续直接调用。点击“复制到 mdo 工具目录”可将选定程序及明确填写的分发目录复制进托管目录，保留原文件，并获得可迁移入口。需要 DLL、运行库的程序应明确填写完整分发目录；不推测依赖、不扫描系统。托管目录中的程序路径由安装管理，改用其他程序时添加新的自定义条目。

清单可声明多个命令，每个 `entry` 必须指向 `files` 中的非空文件，`args` 是逐项传递的字符串数组，允许空字符串：

```json
"commands": [
  {"name":"ssh", "entry":"openssh/ssh.exe", "args":[]},
  {"name":"scp", "entry":"openssh/scp.exe", "args":[]},
  {"name":"grep", "entry":"busybox/busybox.exe", "args":["grep"]}
]
```

一个工具最多 64 个声明命令；每条最多 64 个前置参数。名称仅使用字母、数字及 `_.+-`，拒绝 Windows 设备保留名和 `.exe` 后缀。Windows 名称大小写不敏感。发行工具会在独立归档中携带明确的命令清单；分享和本地复制保留自定义命令及别名。旧版官方归档有固定的 OpenSSH、Python、BusyBox 入口补全，不执行探测程序。

Android 不包含或释放 Windows 转发器。lite 不携带外部原生程序；full 继续由 PackageManager 安装原生库，私有运行树链接到 APK 安装的文件，禁止下载可执行文件。full 的 PATH 包含 BusyBox、curl、jq、OpenSSH、Python、aria2、ripgrep、7-Zip 的预制入口。

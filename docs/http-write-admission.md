# HTTP 写入准入与旧页面保护

项目清除后，旧标签页仍可能持有草稿、待发意图和上次会话选择。只暂停执行
清除的页面不足以防止其他页面在清除完成、意图确认移除，甚至同名项目重建
后写回旧数据。`src/api/write_admission.c` 在 HTTP 路由入口检查页面代，并在
清除期间排除普通 HTTP 写入。此机制不新增 Home 文件，不是认证或权限令牌。

## 客户端合同

API 响应携带 `X-Mdo-Write-Token: <32 位随机十六进制>-<十进制代>`。随机部分
每次 API 初始化重新生成，清除代从零开始。前端启动读取并核对
`GET /api/v1/project-purge-intent` 时取得当前页面令牌；页面整个生命周期固定
使用它，后续成功响应、错误响应及重新查询都不得静默更新旧页面的令牌。

普通 POST/PUT/PATCH/DELETE 请求及原始附件上传须携带该头。缺失返回
`428 write_token_required`，重复头返回 `400 write_token_invalid`，不匹配返回
`412 write_token_conflict`，在正文处理和持久写入前拒绝。现有资源 revision/
If-Match 合同仍需独立满足；页面令牌不能代替项目、草稿或其他资源的版本。
辅助脚本应先读取当前令牌。测试的通用请求助手默认在写入前读取新令牌，而
专用旧页面探针关闭该便利功能，显式保留并发送原令牌。

GET/HEAD/OPTIONS 不要求该头。停止既有 Run 可缺省令牌，但仍取得普通写入
准入。取消原清除请求、读取原结果和确认移除意图使用各自的持久绑定，不受
过期页面令牌阻断。清除结果重放仍须满足原请求 ID、项目、版本、创建时间，
不增加清除代；全新清除执行需要当前令牌。保存新意图需要当前令牌。

## 服务端时序

普通变更从路由开始到处理及回复结束持有准入计数。清除取得独占准入；存在
已接纳写入时立即返回 `409 write_admission_busy`，不等待、不接受清除请求、
不移动数据、不改变页面代。独占期间新的普通写入同样返回 409。读取可用。
短互斥锁只保护计数、独占标志和代，不跨处理器或 socket 回调持有。

全新清除在意图动作锁内核对请求凭据及当前页面令牌，然后在可能改动数据
前增加代。之后的预检或清除即使失败也可能已增加代，按保守原则要求旧页面
重新载入；不把 HTTP 失败视为清除未提交。正式结果凭据和 Home 恢复协议
仍决定提交事实。计数/代溢出或初始化不可用时拒绝，随机数失败无弱随机回落。
宿主重启更换随机部分，使前一宿主的迟到 HTTP 写入也失效。

此准入只覆盖正式 HTTP 路由，不能宣称隔离所有后台或 C 调用。后台任务、
工具及其他内部写入仍依赖项目生命周期租约和各存储锁。跨宿主同 Home 的
互斥仍由 Home 进程租约负责，页面令牌也不授权跨进程访问。

## 前端恢复

启动/窗口恢复焦点/恢复可见时读取意图；即便另一页已经确认移除意图而返回
空记录，响应令牌与当前页不同仍会暂停写入。变更请求报告令牌失效时立即
暂停；后续查询成功不会解除该标志。只有真实页面重新载入才重新建立页面代。

失效页面保留草稿内存并提供「复制未发送草稿」和「重新载入」。复制包含
已加载草稿的正文、图片 ID、后续配置、待发意图及运行接纳不明标志，是独立
JSON 快照；不包含图片文件本身，也不代表所有未加载草稿的完整导出。复制
失败显示错误并保留内容。不会自动刷新丢弃用户尚未保存的修改。已验证 abort
确认移除后，失效页面仍保持暂停；提交/未知事实继续保留原编号。

## 有界验证

`tests/test_write_admission_runtime.py` 使用三个隔离的小 Home，验证冷读零创建、
缺失/重复/失效头、原始上传、全局及项目草稿/新项目/新会话/选择迟到写入、
凭据重放与确认、同名重建及宿主重启。两个受控客户端验证两种准入顺序。
夹具只在复制源中把已完成处理器的最终准入释放延后到一个本机线程；不保留
request/socket/栈指针，不在监听回调里阻塞等待第二个连接。该证据验证计数
竞争和路由行为，不代表高并发性能测试。`tests/test_write_token.mjs` 验证固定
页面令牌、JSON/原始上传、空意图后的失效检测及复制快照保留。完整发布门禁
另核对现有 API、打包确定性、便携窗口目录和启动观察。

明确清除确认/执行、在途前端操作排空、提交后草稿/队列/导航收敛仍需下一
阶段接入，不据此开放产品清除入口。没有压力或高负载测试。

# 设备间传输

## 使用

1. 两端使用支持设备传输的 mdo 版本，登录同一账号并开启远程控制。
2. 在接收端的“远控设置”勾选“允许同账号设备发送会话和项目到此设备”，保存。
3. 在会话菜单选择“发送到设备”，或在项目菜单选择“发送完整项目到设备”。
4. 选择设备；单会话选择接收项目，完整项目选择接收目录，确认开始。
5. 从“远控设置 → 设备传输任务”查看状态、重试或打开结果。

保存目录留空时，完整项目放入目标 Home 的 `workspace/received-projects/mdo-<传输 ID>`。
指定目录是接收端已经存在的父目录；实际项目仍放进其下全新的 `mdo-<传输 ID>` 子目录。
现有目录、项目和会话不会被覆盖。发送前会保存当前界面管理的草稿；保存失败时不开始传输。

| 类型 | 复制内容 |
| --- | --- |
| 单会话 | 模型账本、UI 历史、用量、附件、产物、计划、草稿及暂存队列 |
| 完整项目 | 所有会话（含归档和回收站）、工作目录全部普通文件和目录、项目记忆 |

隐藏文件、独立 Git 仓库的 `.git`、未跟踪文件也属于工作目录。单会话不附带工作目录或项目记忆。
运行中的进程、登录凭据、全局设置、全局记忆、自定义模型及 Agent 定义不复制。
接收端继续执行前，需要有对应模型和 Agent 配置；队列保持待确认，不自动调用模型或工具。
每次发送创建独立副本，后续修改不会同步；源数据始终保留。

## 一致性、恢复和网络

发送由原生后台任务执行。浏览器只提交任务和查询状态，关闭弹窗不会停止传输。
整个项目准备阶段取得项目排他租约，等待运行结束，并暂时阻止 mdo 对项目的访问；
工作目录及记忆会复制并再次核对。网络发送阶段释放租约，传输固定副本。
外部程序继续修改文件时，准备会失败并保留明确提示，不会声称完整发送。

原生连接复用远控授权：同账号控制票据、写令牌、请求序号、校验和与流量确认。
可用时使用经过证书校验的局域网 TLS 连接，否则经现有服务器中转。
中转使用现有远控安全边界；本功能没有增加独立的端到端加密层。

原生发送和接收分别由独立线程处理。分块落盘并刷新后确认偏移；断线后查询原任务的持久化偏移再续传。
暂时的连接失败持续重试并逐步延长等待，成功连接后重置等待；明确的账号、接收开关、空间、路径或格式错误暂停等待处理。
应用重启后继续持久化队列，不重新创建目标。重新授权产生新设备记录时，可选择原接收设备的新记录后重试；
原生层要求该记录包含原任务、接收 Home 身份和相同清单，不能把同一任务悄悄改发另一台设备。
退出账号或更换账号会停止原账号的工作；重新登录后可从任务列表继续。

接收端先写私有暂存目录，校验全部数据，重新分配会话/项目 ID，重绑工作目录并准备会话恢复产物。
半成品通过持久化标记隐藏；最终提交后才移除标记并通知界面更新。
提交中途退出，按原任务及目录身份、文件校验收据恢复；同一任务重复请求不会再生成一份数据。
收到最终提交请求后不提供取消，以免把结果不确定的提交当作已回滚；失败时保留数据供继续完成。
完成或取消后后台回收原始传输文件，保留任务状态和校验收据。

传输期间使用原生防休眠与 Android 后台租约；Android 被系统强制停止后，需要重新打开应用继续。
自动休眠抑制不能保证绕过系统强制关机、应用强杀或用户手动休眠。

## 存储合同和限制

任务位于 `mdo-home/data/device-transfers/`，接收策略位于 `config/device-transfer.json`。
`queue.json` 是持久化运行索引，发送和接收各最多 16 个未结束任务；已完成记录不占运行槽位。
`outgoing/<ID>` 保存固定清单与源文件副本，`incoming/<ID>` 保存分块、恢复暂存和提交收据。
传输数据按账号隔离；重新接收必须由当前账号明确开启。

- 项目总量通过文件分块传输，不受单会话 JSON 的 64 MiB 原始备份总量约束。
- 每个会话仍使用现有恢复校验：单文件最多 32 MiB、原始会话数据合计最多 64 MiB、编码文档最多 96 MiB。
- 每次最多 100,000 项，清单最多 64 MiB，路径最多 2,048 UTF-8 字节，目录深度最多 64。
- 当前版本拒绝符号链接、特殊文件、指向目录外的 Git worktree 元数据以及不能跨平台表示的文件名，明确暂停，不跳过文件。
- 接收前检查磁盘余量和原子排他改名能力。部分网络盘和 WSL 的 Windows 挂载目录不支持该操作，需要使用受支持的本地文件系统。
- 单会话只能放入现有目标项目；目标项目定义或实际目录在确认后被替换时拒绝提交。
- 发送和接收均需要额外暂存空间。接收阶段保守预留双倍声明数据量与 32 MiB 余量，指定项目父目录另检查空间。

## 回归

`tests/test_device_transfer_runtime.py` 使用两个真实原生 mdo、一次性账号和中转服务、本地模拟模型。
覆盖 65 MiB 项目文件、草稿、暂存队列、回收站、项目记忆、源数据不变、目标会话继续调用、
重复请求冲突、非法清单、两端上传中重启、隐藏提交中断恢复和强制中转。
故障注入只修改测试副本，不进入产品源码。
`tests/test_device_transfer_panel.mjs` 覆盖丢失创建回执后复用 ID，以及切换任务后丢弃旧响应。
本轮验证记录见[构建记录](build-records/2026-10-18-device-transfers.md)。

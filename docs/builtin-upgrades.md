# 内置扩展升级

内置 Agent、编辑器命令和 Skill 与其他扩展使用相同的目录模型；随程序打包的归档负责首次安装及后续升级。

- 启动时根据安装收据检查目录摘要。未修改的旧内置目录自动更新，包括尚未声明逻辑 ID 的旧版本；不需要手动迁移。
- 安装事务再次核对目录修订，保留已有停用设置。已有首次安装收据、但目录已卸载时，不重新创建。
- 本地修改、无法验证的内容及非内置来源不被覆盖。需要处理的内置目录显示集中警告。
- 有效清单下的内置程序若未通过收据校验，首次启动时隔离该定义，保留设置和修复界面。运行中重新加载失败则保留原活动定义集合，不发布不完整的新集合。
- 默认 Agent 不可用时，创建、打开、运行和恢复路径返回 `agent_unavailable`。界面说明安装、启停或加载问题，并提供“检查 Agent”入口；模型配置错误继续使用独立错误码。

历史回归使用真实 0.7.0 内置 ZIP 和安装收据；覆盖自动升级后创建会话、停用/卸载保留、修改保护、警告和幂等重启。原 0.8.0 发行物可通过同一夹具重现“默认 Agent 不存在却报会话配置无效”的错误。

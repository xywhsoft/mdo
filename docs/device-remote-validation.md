### 完全允许后台行为后的实机结果

测试使用同签名 versionCode `20261023`、xs `f025c17` 和真实线上 HTTPS/WSS。原有两个手机会话及控制端本机会话保持不变：

- 后台：墨斗退出前台数分钟，线上读取会话仍成功，每 10 秒续期正常；经中继新建验收会话并调用内建 Ornith，回复“后台远控成功”，目标导出包含已保存结果，控制端没有创建任务。
- 锁屏：系统 `mWakefulness=Asleep`，在记录锁屏基线 100.8 秒后线上读取手机会话成功；随后新建任务、调用模型、收到终态并导出已保存结果均在锁屏期间完成。验收会话 `V-OS3ACLtLgHGqgU3yVJhCiF5P60PLya`，对应任务 `run-V-OS3ACY6wTuQn6PfHFoR25hqCTTYXbB`。这些是新建的测试数据，不包含用户原有会话正文。
- 最终 UI 增加目标平台元数据及 Android 专用说明，中文、英文、俄文一致；只读远控浏览会话不再尝试写入上次选择，回归验证导航可用且没有修改请求。

页面说明入口为“设置 → 设备远控 → 允许远程控制”。提示用户在**目标手机**系统的应用信息、电池或耗电管理中允许后台运行；部分机型需要“完全允许后台行为”或“不受限制”。通知权限建议开启，以显示常驻服务状态与停止入口；它不是启动前台服务的必需授权。若系统提供应用速冻/休眠选项，可取消对墨斗的限制。开启远控可能增加耗电；强制停止、系统重启或更严格的后台策略仍可能导致离线，需要重新打开应用确认状态。

以上是已验证设备和设置下的有界结果，不代表所有 Android 厂商、长时间休眠或系统重启后的无限在线保证。最终文案更新包 versionCode `20261024` 复用同一 SDK、签名及后台机制；文案变更不重复整个锁屏测试。

实机测试先记录 APK 版本、设备权限、目标选中状态和原有会话 ID；锁屏后经线上中继读取目标并发送一条只回复固定文字的消息。核对目标保存、控制端未创建任务、事件/终态一致。测试 CPU 租约停止时核对系统锁释放。结束后恢复测试账号与远控开关的初始状态，保留用户数据；只撤销测试创建的临时系统设置。

不进行压力、高负载测试，不将短时在线解释为无限后台保证。

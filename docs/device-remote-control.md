# 设备远程控制实施计划

状态：实施中。范围已确认，面向所有已登录会员开放。首版由墨斗 PC / Android 控制，网站控制入口后续另行实现。

2026-10-05 进度：xadmin 通用托管通道已实现。真实 xs/TCC 的明文和 TLS 功能测试通过，覆盖会员注销、插件换代及宿主换代、二进制/分片和有界队列；设备中继及墨斗原生/前端尚未完成，线上尚未部署。xadmin 开发分支为 `codex/device-relay`，墨斗为 `codex/device-remote-control`。

## 不可破坏的行为

1. 选择设备后，对话、项目、会话、文件、工具、权限、模型、设置、账号、更新等操作全部作用于目标设备。不存在自动回退本机的路径。
2. 连接器负责选择目标、断开和返回本机；目标设备内部的账号或设置不改变控制端身份。前端物理输入、显示和剪贴板由当前终端承载。
3. 切换设备撤销旧请求及订阅，隔离草稿、写入令牌、缓存和迟到结果。断线保留目标，并禁止发送新操作；已启动的任务继续运行。
4. 本机默认关闭远控。设备主动连接中继，不要求开放入站端口。关闭或撤销设备后不静默重新注册。
5. 同账号校验来自服务端已验证的会员会话，不能相信客户端传入的所有者。跨账号设备不可查询、连接或撤销。
6. 请求正文、响应正文、附件和事件只在内存中转发，不写数据库、访问日志或诊断日志。首版使用 TLS，中继可见转发内容；不承诺端到端加密。
7. 远端不支持的系统能力明确不可用；不能在控制端悄悄执行。远控请求仍使用目标设备的写入代际、项目租约、权限和任务规则。

## 分层和目录

- xadmin `src/net/plugin_channel.c`：通用托管 WebSocket 通道。提供接管、发送、关闭、状态及插件停用时取消/回收能力，不包含墨斗特例。
- xadmin `plugin_sdk/xs_plugin.h`：追加通道 API，保留插件 ABI v4 描述符布局。
- xadmin `plugin/device-relay/`：设备登记、列表、撤销、连接票据和同账号转发。设备元数据存插件私有数据库，通道和票据仅在内存中。
- mdo `app/src/remote/`：目标设备配置、出站连接、认证更新、协议、请求派发及生命周期。
- mdo `app/web/js/api/`：统一传输接口、本机和远程实现、设备上下文及取消隔离。
- mdo 设备切换入口位于侧栏，远控设置位于设置页；不增加输入框工具栏行数。

## 通道和协议边界

通道拥有服务器、流及编译单元生命周期，不能用无限期的异步 HTTP 路由代替。保留 xs 的流回调/脚本租约。所有插件回调仍由宿主锁串行调度；网络等待不持有该锁。消息大小、输出队列、连接数、握手、发送和空闲时间都有上限。关闭回调至多一次，插件卸载前停止并等待其通道。

连接先协商协议版本与能力。目标设备和控制端分别获取短时、单次、绑定角色和设备的连接票据；认证材料不放 URL 查询串。设备 ID 为稳定随机值。服务端再次校验会话存活、设备状态和所有权，注销、封禁或撤销后关闭通道。

转发覆盖普通请求、二进制上传下载、事件订阅、ask 和权限确认。大文件采用有界分块，不能堵塞心跳或控制消息。写请求携带唯一请求 ID 和内容指纹；丢失响应不能盲目重放写操作，先查询执行状态或已有资源。目标设备负责去重并返回同一次操作结果。

## 分阶段交付和提交

1. **契约和生命周期**：文档、通用通道、认证再校验、插件关闭/重载回收，配套小规模功能测试；提交 xadmin。
2. **设备中继**：私有数据库迁移、会员 API、票据、上线状态、转发、撤销及后台配置；本地隔离测试通过后提交 xadmin。
3. **原生服务**：统一请求派发适配、凭据存储、WSS 重连、事件和二进制传输、写请求去重；提交 mdo。
4. **前端体验**：统一传输、设备列表/切换、远控设置、所有页面及下载/图片/native 动作适配；提交 mdo。
5. **集成与发布**：两个独立墨斗实例验证，服务器隔离验证，然后部署生产站点；服务器变更同步到 D:\GIT\home 并提交，生成 PC/APK 并按可用设备实测。

每个功能或阶段完成后提交 Git。原工作区的其他在途改动不混入本任务。使用独立 worktree，最终集成保留已有改动。

## 验收矩阵

- 同账号连接成功、跨账号访问拒绝、未登录拒绝、票据重复使用拒绝。
- 会话过期/注销/封禁、设备撤销、插件停用/重载、服务退出均回收连接与编译单元，不留下回调或流引用。
- 对话流式事件、工具、权限弹层、ask、附件、项目/会话增删改、全部设置均映射目标。
- 连接失败不落本机；设备切换时迟到响应不污染新设备；写入响应丢失不重复创建任务。
- 两个控制连接的小规模并发、断线重连、慢连接和格式错误的边界验证；不进行压力或高负载测试。
- Windows/Linux 构建与功能验证；Android 前台和实际后台限制按实机结果说明，不承诺手机无限后台在线。

线上操作保留数据库和私有密钥，只部署本阶段需要的宿主/插件文件。生产重启已获授权；部署前准备可回滚的文件快照和完成的功能测试结果。

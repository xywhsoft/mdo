本阶段修改 `api/client.js`、`state/settings.js` 和 `app.js`，没有放宽服务确认或清除审核围栏。候选基于 `3d83bdc0` 的干净工作树，使用锁定的 xs `7e4eb8a090cae67f33f0e1afa2b24dea66781efa` 宿主；不包含同期其他任务的未提交修改。

# 原生桌面复制与实际下载验收入口

基线 `9dc2356`；本阶段没有修改产品代码，也没有把复制或下载交接当作系统剪贴板和文件落盘的证据。

`manual_desktop_export_qa.py` 使用已验证的独立 Windows 候选和全新的便携 Home，通过真实设置 API 添加回环模型，创建独立会话。配置完成后显式结束初始化 HTTP 服务，再以同一 Home 的正式 `class: app` 服务启动原生 WebView2 窗口，直接打开测试会话。窗口拥有独立标题、程序路径和 WebView2 数据目录，不使用用户日常会话。

本次已确认真实 HTTP 初始化、模型配置、会话保存、服务重启和原生窗口建立。环境变量 `USE_WEBVIEW=1` 并不能把 `class: http` 服务变成窗口服务，夹具改为使用正式 app 配置。`initialization.json` 记录候选摘要和明确的未完成项目。

原生截图在重新选择窗口后仍超时。尝试通过普通 Chrome 的控件树验证时，工具因无法可靠判断当前浏览器 URL 停止该轮原生输入。没有继续输入，也没有进行复制、发送模型请求或点击导出；仅结束本任务拥有的测试进程。系统剪贴板、Markdown/备份实际保存以及 Android 真机仍未验收，不能据此判定产品失败或通过。

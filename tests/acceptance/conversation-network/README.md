# 断网和本地服务重启验收

2026-10-08，在独立便携目录通过正式工作台完成浏览器操作。
模型仅访问回环服务，测试图片和文字均为固定样例，没有使用用户会话或付费接口。

发现并修复：后台时间线读取失败留下错误卡，空恢复状态读取失败误报
“上次回复未完成”，HTTP 已断而 WebSocket 仍显得正常时反复保存草稿，
服务重启后使用旧凭证无法恢复订阅，以及重新载入错误地返回首页。

现在后台可恢复读取保留历史并以有上限的退避重试。连接中仅显示轻量状态，
仍允许本地编辑。HTTP 失败会触发连接检查并暂停草稿保存；网络恢复后
重新保存本地修改。旧的网络保存错误不会在恢复时再闪现。永久访问失败
和真正未确认的执行结果继续保留准确提示，不因临时读失败而解除执行保护。

实际验收包括：断网 → 编辑含图片草稿 → 恢复网络 → 自动保存 → 手动发送；
以及已保存草稿 → 原生宿主停止 → 同一目录重启 → 读取历史恢复 →
点击“重新连接”和“重新载入页面” → 仍留在原会话 → 图片与文字可见 → 续聊。
两组各 2 次模型调用、零最终错误；用户消息和图片没有重复发送。

真正重启时仅更新读取订阅凭证，旧页面的写入凭证继续受保护，需要显式
重新载入后再发送，避免旧队列或工具操作重复执行。临时网络中断无需重新载入。
`manual_conversation_retry_qa.py` 支持创建隔离目录的 `restart` 文件触发有界停机，
`--restart-wait` 设置 0.5–15 秒等待；`stop` 文件结束测试。只操作其自建的宿主副本。

退避、切页、隐藏页面、取消、旧请求、恢复卡可见性、写入保护及本地化的
检查通过；连接、恢复与备份相关检查合计 76 项，另有 26 项草稿/恢复/会话检查和
20 项前端契约检查通过。未进行压力或高负载测试。

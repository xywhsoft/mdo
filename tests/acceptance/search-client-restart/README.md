# 未完成搜索在客户端重启后的恢复

2026-10-09。mdo 实现 `3a4d54c5`，干净测试源码 `a1643ce7`；xwork
`90e4dc0f`（3.10.0，ABI 7），xs `9a0f5f6f`。本阶段仅隔离环境，未发布日用
程序、手机安装包或网站；未做压力或高负载测试。

搜索提交前，通过 xwork 的 live v2 回调入口原子保存随机编号。记录在会话
`artifacts/requests/`，以原来源、工具、调用编号、原参数和轮次定位，绑定服务
与会员。既有编号在未完成工具重新执行时复用；保存失败、记录损坏或范围变化
不给替代编号。没有记录凭据、搜索正文，未增加模型工具参数或额外工具。

恢复后的请求禁止旧接口回退，因为上一个进程可能已使用旧 POST。编号年龄达到
23 小时 55 分钟或系统时钟回退时也不再提交，保守落在网站 24 小时键保留期内。
可用结果的十分钟保留期仍由网站决定；过期结果准确结束，不另收费重新搜索。

`baseline-clean.json` 将旧 `66d65df5` 搜索回调放入同一隔离宿主，实际终止一个
客户端进程，再由第二个进程恢复原会话账本。复现两次平台提交、两次额度扣减，
编号变化。这是旧搜索回调的对照，不声称整套旧 mdo 的所有边界均重新运行。

`client-restart-clean.json` 使用干净源码、真实 mdo 会话/账本/xwork/原生 HTTP，
经回环故障代理访问真实统一网站插件/JWT/额度存储。平台 HTTP 和模型完成回调
是本地模拟；各组两个独立客户端进程，没有用同进程重建对象冒充进程重启。

| 场景 | HTTP 次数 | 平台提交/额度 | 恢复行为 |
| --- | ---: | ---: | --- |
| 平台结果已保存，客户端收到前退出 | 2 | 1/1 | 同编号、同正文取回结果 |
| 编号已保存，提交平台前退出 | 2 | 1/1 | 同编号完成首次提交 |
| 旧路由已提交但响应丢失 | 3 | 1/1 | 恢复遇到新路由 404 后停止，无第二次旧 POST |
| 恢复时会员变化 | 1 | 1/1 | 新进程零 HTTP，不改编号 |
| 编号超过安全年龄 | 1 | 1/1 | 新进程零 HTTP，不改编号 |
| 时钟回退使编号处于未来 | 1 | 1/1 | 新进程零 HTTP，不改编号 |
| 编号记录损坏 | 1 | 1/1 | 新进程零 HTTP，不改编号 |

每组恢复后仅一个最终工具完成事件；成功组仅一个结果产物。拒绝组把准确失败
作为一个工具结果交给模型，Agent 仍正常结束。第二个进程只调用模型一次，
没有要求模型重新发起搜索；原用户输入在两个进程观察的模型账本中均仅出现
一次。验证的是产品事件流，尚未进行真实浏览器页面或 Android 真机验收。

`xwork-request-tokens.txt`：18 项严格 C 编译后的定向检查，包括存储重建、
账号/服务绑定、参数/轮次隔离、损坏、发布失败、非覆盖发布竞争和无存储回调。
测试桥接使用锁定 xs 生成的 xhttp/xrt 核心（含 `xrtRootRenameNoReplace`），没有
为链接测试替换文件系统实现。xs 的 23 个生产文件与上游逐字节一致，36 项扩展
检查包含一项 Linux 平台跳过，178 个 xwork 外部 API 全部导入。

`native-recovery.json`、`lost-regression.json`、`page-regression.json` 保留 25 项
原生搜索恢复、10 组真实插件故障代理与 20 项网页恢复回归；`session-quota.json`
验证额度拒绝仅一个失败工具结果，随后 Agent 正常结束。16 项干净构建契约及
候选打包启动、搜索开关/迁移/保存通过。`candidate.json` 为干净源码的独立
Windows 候选，4,515,427 字节，两个生产文件已与包内来源逐字节核对。

有意保留的范围：嵌套任务、关闭持久化及没有可写会话存储的回调只有本次执行
内的编号保障；手动删除恢复文件会丢失保障。该入口只配合外部幂等协议，不使
任意 POST 或写工具自动变得可重试。外部线上服务、真实模型、浏览器与 Android
验证，以及其他功能检查仍属于长期任务后续工作。
